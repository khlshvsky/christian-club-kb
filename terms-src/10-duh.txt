## Учение о Духе Святом
- Утешитель {Παράκλητος} :: Имя Духа Святого, обетованного Христом апостолам. [[Ин 14:26]] => Дух Святой
- Господь Животворящий :: Исповедание Символа веры о Духе Святом: Он — истинный Бог, источник жизни. => Никео-Цареградский Символ веры; Дух Святой
- Сошествие Святого Духа :: Излияние Духа Святого на апостолов в пятидесятый день по Воскресении; рождение Церкви. [[Деян 2:1-4]] => Пятидесятница; Церковь
- Стяжание Духа Святого :: Цель христианской жизни по прп. Серафиму Саровскому: приобретение благодати Духа через молитву, пост, милостыню и все добрые дела. => Серафим Саровский; Обожение
- Харизмы {χαρίσματα} :: Особые дары Духа для служения Церкви: пророчества, исцеления, учительства и др. [[1 Кор 12:4-11]] => Дары Святого Духа
- Помазание Духом :: Сообщение даров Духа верующим, совершаемое в Таинстве Миропомазания. [[1 Ин 2:20]] => Миропомазание

## Семь даров Святого Духа
- Дары Святого Духа :: Семь даров по пророку Исаии: дух премудрости, разума, совета, крепости, ведения, благочестия и страха Божия (Катихизис). [[Ис 11:2-3]] => Миропомазание; Харизмы
- Дух премудрости :: Дар познавать Бога и Божественное и устроять жизнь по воле Божией. => Дары Святого Духа
- Дух разума :: Дар разумевать истины веры и Писание. [[Лк 24:45]] => Дары Святого Духа
- Дух совета :: Дар благоразумия в выборе добра в трудных обстоятельствах. => Дары Святого Духа
- Дух крепости :: Дар мужества в исповедании веры и борьбе с искушениями. => Дары Святого Духа
- Дух ведения :: Дар познавать волю Божию и истинную цену вещей. => Дары Святого Духа
- Дух благочестия :: Дар сыновней любви к Богу и благоговения в служении Ему. => Дары Святого Духа
- Дух страха Божия :: Дар благоговейного опасения оскорбить Бога грехом; «начало премудрости». [[Притч 1:7]] => Страх Божий

## Плоды Духа
- Плоды Духа :: Добродетели, рождаемые Духом в христианине: любовь, радость, мир, долготерпение, благость, милосердие, вера, кротость, воздержание. [[Гал 5:22-23]] => Добродетель
- Радость о Духе :: Духовная радость, которую не может отнять мир. [[Рим 14:17]] => Плоды Духа
- Мир душевный :: Внутренний мир, даруемый Христом, — признак благодати. [[Ин 14:27]] => Плоды Духа; Бесстрастие
- Долготерпение :: Терпеливое перенесение скорбей и обид без ропота. [[Кол 1:11]] => Терпение
