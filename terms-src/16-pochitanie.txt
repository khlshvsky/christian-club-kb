## Иконопочитание
- Икона {εἰκών} :: «Образ» — священное изображение Христа, Богородицы, ангелов и святых; почитание переходит к первообразу. => Первообраз; Иконопочитание; VII Вселенский Собор
- Первообраз :: Лицо, изображённое на иконе; честь, воздаваемая образу, восходит к первообразу (свт. Василий Великий). => Икона
- Иконопочитание :: Благоговейное поклонение святым иконам, утверждённое VII Вселенским Собором; основано на Боговоплощении. => Иконоборчество; Торжество Православия
- Служение (латрия) {λατρεία} :: Богопоклонение, подобающее одному Богу. [[Мф 4:10]] => Почитательное поклонение
- Почитательное поклонение {προσκύνησις τιμητική} :: Почитание, воздаваемое иконам, святым и святыне, — не то служение, которое подобает только Богу (VII Вселенский Собор). => Служение (латрия)
- Нерукотворный образ :: Образ Спасителя, чудесно запечатлённый на убрусе; основание иконописания в Предании. => Икона
- Канон иконописный :: Предание Церкви о составе и образе написания икон. => Икона; Андрей Рублёв
- Освящение иконы :: Чин, которым образ посвящается Богу и делается святыней. => Икона
- Чудотворная икона :: Икона, через которую Бог являет чудеса по молитвам верующих. => Чудо

## Святые
- Святые :: Угодившие Богу люди, прославленные Им; их молитвенная помощь — проявление единства Церкви земной и небесной. [[Иак 5:16]] => Призывание святых; Лики святости; Канонизация
- Призывание святых :: Молитвенное обращение к святым как к ходатаям перед Богом. => Святые; Церковь торжествующая
- Канонизация :: Прославление Церковью подвижника в лике святых. => Святые
- Лики святости :: Разряды святых по роду их служения и подвига. => Апостолы; Мученики; Преподобные; Святители
- Апостолы :: Ученики Христовы, посланные проповедовать Евангелие: двенадцать и семьдесят. [[Мф 10:2-4]] => Равноапостольные
- Равноапостольные :: Святые, равные апостолам по подвигу просвещения народов (Константин и Елена, Кирилл и Мефодий, Ольга, Владимир). => Апостолы
- Пророки (лик) :: Ветхозаветные праведники, предвозвестившие пришествие Мессии. => Пророк
- Праотцы :: Ветхозаветные праведники-родоначальники Спасителя по плоти; празднуются перед Рождеством. => Пророки (лик)
- Мученики :: Пострадавшие за Христа; великомученики — претерпевшие особо тяжкие мучения. [[Откр 2:10]] => Мученичество
- Священномученики :: Мученики из священного сана. => Мученики
- Преподобные :: Святые монахи, уподобившиеся Богу подвижнической жизнью. => Монашество
- Преподобномученики :: Монахи, принявшие мученическую кончину. => Мученики
- Исповедники :: Святые, пострадавшие за веру, но не убитые. => Мученики
- Святители :: Святые епископы. => Епископ
- Бессребреники :: Святые врачи, безмездно исцелявшие больных (Косма и Дамиан, Пантелеимон). => Святые
- Благоверные :: Святые миряне — князья и правители. => Святые
- Юродивые Христа ради :: Подвижники, принявшие вид безумия ради Христа (Василий Блаженный, Ксения Петербургская). [[1 Кор 4:10]] => Святые
- Праведные :: Святые, угодившие Богу в мирской жизни и семье. => Святые
- Страстотерпцы :: Святые, со смирением претерпевшие насильственную смерть (Борис и Глеб). => Мученики
- Новомученики и исповедники Российские :: Пострадавшие за веру в годы гонений XX века. => Мученики
- Мученичество :: Свидетельство о Христе до крови; «кровь мучеников — семя христианства». => Мученики; Гонения на христиан

## Святыни
- Мощи :: Останки святых, через которые действует благодать Божия. [[4 Цар 13:21]] => Антиминс; Святые
- Крест :: Орудие спасительной смерти Христа и знамение победы над смертью; почитается как святыня. [[Гал 6:14]] => Крестное знамение; Воздвижение Креста Господня
- Крестное знамение :: Изображение креста на себе с призыванием Святой Троицы; православные крестятся тремя перстами. => Крест; Двоеперстие
- Святая вода :: Освящённая вода (агиасма), подающая освящение и исцеление. => Великое освящение воды
- Артос :: Квасной хлеб, освящаемый на Пасху и раздаваемый в субботу Светлой седмицы. => Пасха
- Святыня :: Всё, посвящённое Богу и освящённое Церковью: храмы, иконы, мощи, священные предметы. => Храм; Икона
- Паломничество :: Благочестивое путешествие к святым местам и святыням. => Святыня
