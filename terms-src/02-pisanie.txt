## Библия и её состав
- Библия {τὰ βιβλία} :: «Книги» — собрание богодухновенных книг Ветхого и Нового Завета. => Священное Писание; Ветхий Завет; Новый Завет
- Богодухновенность :: Свойство Писания: оно написано людьми по внушению и под водительством Духа Святого. [[2 Пет 1:21]] => Священное Писание; Пророк
- Завет :: Союз Бога с человеком; по Завету делится и Писание: Ветхий — до пришествия Спасителя, Новый — после. [[Иер 31:31]] => Ветхий Завет; Новый Завет
- Ветхий Завет :: Священные книги, написанные до Рождества Христова; содержат закон, историю, учение и пророчества о Мессии. => Пятикнижие; Исторические книги; Учительные книги; Пророческие книги
- Новый Завет :: 27 книг, написанных апостолами после пришествия Спасителя: Евангелия, Деяния, послания, Апокалипсис. => Евангелие; Апостол (книга); Апокалипсис
- Канонические книги :: Книги, признанные Церковью богодухновенными; в Ветхом Завете их 39 (по древнему еврейскому счёту — 22), в Новом — 27. => Неканонические книги; Каноны Священного Писания
- Неканонические книги :: Книги Ветхого Завета, не вошедшие в еврейский канон (Товит, Иудифь, Премудрость Соломона, Сирах, Маккавейские и др.); Церковь предлагает их для чтения как полезные и назидательные. => Канонические книги; Септуагинта
- Апокрифы {ἀπόκρυφα} :: Сочинения, выдававшие себя за священные, но отвергнутые Церковью и не читаемые за богослужением. => Канонические книги
- Пятикнижие :: Пять книг Моисея — Бытие, Исход, Левит, Числа, Второзаконие; называется также Законом (Тора). => Ветхий Завет; Моисеев закон
- Исторические книги :: Книги, повествующие об истории народа Божия от Иисуса Навина до Маккавеев. => Ветхий Завет
- Учительные книги :: Иов, Псалтирь, Притчи, Екклезиаст, Песнь песней и др. — книги, наставляющие в вере и благочестии. => Псалтирь; Ветхий Завет
- Пророческие книги :: Книги великих (Исаия, Иеремия, Иезекииль, Даниил) и малых пророков, содержащие пророчества о Христе и Церкви. => Пророк; Мессианские пророчества
- Псалтирь :: Книга 150 псалмов; основа православного богослужения и молитвенного правила. => Кафизма; Учительные книги
- Евангелие {εὐαγγέλιον} :: «Благая весть» о спасении через Иисуса Христа; четыре книги — от Матфея, Марка, Луки и Иоанна. [[Мк 1:1]] => Синоптические Евангелия; Новый Завет
- Синоптические Евангелия :: Евангелия от Матфея, Марка и Луки, сходные по составу и порядку повествования. => Евангелие
- Апостол (книга) :: Богослужебная книга с Деяниями и посланиями апостолов; также общее название этих книг. => Новый Завет
- Апокалипсис {ἀποκάλυψις} :: «Откровение» святого Иоанна Богослова — пророческая книга о судьбах Церкви и мира и о Втором пришествии. [[Откр 1:1]] => Второе пришествие; Антихрист
- Соборные послания :: Семь посланий апостолов Иакова, Петра, Иоанна и Иуды, обращённые ко всем христианам. => Новый Завет
- Септуагинта {LXX} :: Греческий перевод Ветхого Завета «семидесяти толковников» (III–II вв. до Р. Х.); им пользовались апостолы, на нём основан церковнославянский перевод. => Неканонические книги; Церковнославянская Библия
- Масоретский текст :: Еврейский текст Ветхого Завета, установленный иудейскими книжниками (масоретами) в VI–X вв. => Септуагинта
- Церковнославянская Библия :: Перевод Писания, начатый святыми Кириллом и Мефодием; используется в богослужении Русской Церкви. => Септуагинта; Кирилл и Мефодий
- Синодальный перевод :: Русский перевод Библии, изданный по благословению Святейшего Синода в 1876 г. => Библия

## Толкование Писания
- Толкование Писания :: Уяснение смысла Писания в согласии с Преданием и толкованием святых отцов. [[2 Пет 1:20]] => Экзегетика; Святые отцы
- Герменевтика :: Учение о правилах и принципах толкования Священного Писания. => Экзегетика
- Буквальный смысл :: Прямой исторический смысл текста Писания. => Духовный смысл
- Духовный смысл :: Смысл, раскрывающий через события и образы Писания тайну Христа, Церкви и спасения. => Прообраз; Буквальный смысл
- Прообраз {τύπος} :: Ветхозаветное лицо, событие или установление, предызображающее Христа и новозаветные тайны (агнец пасхальный, медный змий, Иона во чреве кита). [[Ин 3:14]] => Духовный смысл; Агнец Божий
- Пророчество :: Предвозвещение будущего и возвещение воли Божией по откровению Духа Святого. [[2 Пет 1:21]] => Пророк; Мессианские пророчества
- Мессианские пророчества :: Ветхозаветные предсказания о Мессии: о рождении от Девы, о страданиях, смерти и воскресении. [[Ис 7:14]] [[Ис 53:5]] => Мессия; Протоевангелие
- Протоевангелие :: Первое обетование о Спасителе, данное после грехопадения: Семя жены сотрёт главу змия. [[Быт 3:15]] => Мессианские пророчества; Грехопадение
- Притча :: Иносказательное повествование, которым Господь возвещал тайны Царствия Божия. [[Мф 13:34]] => Евангелие
- Пророк :: Человек, через которого Бог возвещал Свою волю и предсказывал будущее. => Пророческие книги; Пророчество
- Моисеев закон :: Закон, данный Богом через Моисея на Синае: нравственный, обрядовый и гражданский. [[Гал 3:24]] => Десятословие; Пятикнижие
