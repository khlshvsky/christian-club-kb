## Древняя Церковь
- Апостольский век :: Время проповеди апостолов (I в.): основание Церкви и написание новозаветных книг. => Апостолы; Пятидесятница
- Иерусалимский апостольский собор :: Собор апостолов около 49 г., освободивший обращённых язычников от обрядового закона. [[Деян 15:28-29]] => Собор (церковный)
- Гонения на христиан :: Преследования Церкви в Римской империи (I–IV вв.): Нерон, Деций, Диоклетиан и др. => Мученичество
- Катакомбы :: Подземные кладбища Рима, где христиане погребали мучеников и совершали богослужения. => Гонения на христиан
- Миланский эдикт :: Указ 313 г. императоров Константина и Лициния о свободе христианского вероисповедания. => Константин Великий
- Константин Великий :: Равноапостольный император, даровавший Церкви свободу и созвавший I Вселенский Собор. => Миланский эдикт; I Вселенский Собор
- Византия :: Восточная Римская империя (IV–XV вв.) с центром в Константинополе — колыбель православной культуры. => Симфония властей
- Симфония властей :: Византийский идеал согласного союза Церкви и государства (новелла VI Юстиниана). => Византия

## Вселенские Соборы
- Вселенские Соборы :: Семь Соборов епископов всей Церкви (325–787), определивших догматы веры; их определения неизменны. => I Вселенский Собор; VII Вселенский Собор; Догмат
- I Вселенский Собор :: Никея, 325 г. — осуждено арианство, исповедано единосущие Сына Отцу, составлены первые семь членов Символа веры. => Арианство; Единосущие
- II Вселенский Собор :: Константинополь, 381 г. — осуждено учение Македония, исповедано Божество Святого Духа, дополнен Символ веры. => Духоборчество; Никео-Цареградский Символ веры
- III Вселенский Собор :: Ефес, 431 г. — осуждено несторианство, Дева Мария исповедана Богородицей; запрещено составлять иной Символ веры. => Несторианство; Богородица
- IV Вселенский Собор :: Халкидон, 451 г. — осуждено монофизитство, принят орос о двух естествах во Христе. => Монофизитство; Халкидонский орос
- V Вселенский Собор :: Константинополь, 553 г. — осуждены «Три главы» и заблуждения оригенистов. => Оригенизм; Несторианство
- VI Вселенский Собор :: Константинополь, 680–681 гг. — осуждено монофелитство, исповеданы две воли во Христе. => Монофелитство; Две воли во Христе
- Пято-шестой (Трулльский) Собор :: Константинополь, 691–692 гг. — издал каноны, дополнившие V и VI Соборы. => Канон (правило)
- VII Вселенский Собор :: Никея, 787 г. — осуждено иконоборчество, утверждено иконопочитание. => Иконоборчество; Иконопочитание
- Торжество Православия :: Восстановление иконопочитания в 843 г.; празднуется в первую неделю Великого поста. => Иконопочитание; Великий пост

## Средние века и новое время
- Великая схизма :: Разделение 1054 г. между Римом и православным Востоком. => Папизм; Филиокве
- Крестовые походы :: Военные походы западных христиан (XI–XIII вв.); в 1204 г. крестоносцы разграбили Константинополь, углубив разделение. => Великая схизма
- Флорентийская уния :: Соглашение 1439 г. о подчинении Востока папе; отвергнуто Православной Церковью (свт. Марк Эфесский). => Униатство; Марк Эфесский
- Падение Константинополя :: Взятие столицы Византии турками в 1453 г. => Византия
- Брестская уния :: Подчинение части западнорусских епископов Риму в 1596 г. => Униатство
- Паламитские соборы :: Константинопольские Соборы 1341–1351 гг., утвердившие учение свт. Григория Паламы. => Паламизм
- Послание восточных патриархов :: Исповедание православной веры (1723 г.) против инославных заблуждений. => Пресуществление

## Русская Церковь
- Крещение Руси :: Крещение киевлян при святом князе Владимире в 988 г. => Равноапостольные
- Киевская митрополия :: Митрополия Константинопольского патриархата на Руси (с X в.). => Митрополит
- Автокефалия Русской Церкви :: Самостоятельность, фактически установленная в 1448 г. избранием свт. Ионы. => Автокефалия
- Патриаршество в России :: Учреждено в 1589 г. (первый патриарх — Иов); упразднено в 1721 г., восстановлено в 1917 г. => Патриарх
- Церковный раскол XVII века :: Отделение старообрядцев после исправления книг при патриархе Никоне. => Старообрядчество; Двоеперстие
- Синодальный период :: 1721–1917 гг. — управление Русской Церковью Святейшим Синодом. => Синод
- Поместный Собор 1917–1918 гг. :: Собор, восстановивший патриаршество и избравший свт. Тихона. => Поместный Собор
- Гонения XX века :: Преследования Церкви в СССР; множество новомучеников и исповедников. => Новомученики и исповедники Российские
