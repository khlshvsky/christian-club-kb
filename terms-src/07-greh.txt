## Грехопадение
- Грехопадение :: Нарушение прародителями заповеди Божией в раю по внушению диавола; повлекло утрату благодати, смерть и порчу природы. [[Быт 3:6]] => Прародительский грех; Смерть; Адам
- Прародительский грех :: Грех Адама и Евы и его последствия — тление, смертность и склонность ко греху, переходящие на всех потомков. [[Рим 5:12]] => Грехопадение; Крещение
- Повреждение природы :: Следствие падения: помрачение ума, ослабление воли, расстройство сил души, болезни и смерть. [[Рим 7:19]] => Прародительский грех; Страсть
- Смерть :: Разлучение души с телом, вошедшее в мир через грех; духовная смерть — отлучение души от благодати Божией (Катихизис). [[Рим 6:23]] => Грехопадение; Бессмертие души
- Тление :: Подверженность тела разрушению и смерти как следствие греха. [[1 Кор 15:42]] => Смерть

## Грех
- Грех :: Преступление закона Божия. «Грех есть беззаконие» (Катихизис). [[1 Ин 3:4]] => Страсть; Покаяние (метанойя); Покаяние (Таинство)
- Смертный грех :: Грех, который делает человека виновным вечной смерти, если не исцелён покаянием. [[1 Ин 5:16]] => Грех; Покаяние (Таинство)
- Грех против Духа Святого :: Упорное противление явной истине и благодати, которое не прощается, ибо отвергает само покаяние. [[Мф 12:31]] => Хула на Духа Святого
- Хула на Духа Святого :: Сознательное приписывание дел Божиих диаволу. [[Мк 3:29]] => Грех против Духа Святого
- Искушение :: Побуждение ко греху от диавола, мира или собственной плоти. [[Иак 1:14]] => Прилог; Невидимая брань
- Невидимая брань :: Духовная борьба христианина со страстями и бесами. [[Еф 6:12]] => Трезвение; Бесы
- Страсть {πάθος} :: Укоренившийся греховный навык, порабощающий душу. [[Гал 5:24]] => Восемь главных страстей; Бесстрастие

## Развитие греха
- Прилог :: Первое появление греховного помысла в уме; само по себе ещё не грех (прп. Иоанн Лествичник). => Сочетание; Помысл
- Сочетание :: Собеседование с пришедшим помыслом, внимание к нему. => Прилог; Сосложение
- Сосложение :: Согласие души с греховным помыслом. => Сочетание; Пленение
- Пленение :: Насильственное увлечение сердца помыслом. => Сосложение; Страсть
- Помысл :: Мысль, приходящая в ум; помыслы бывают от Бога, от естества и от бесов. => Прилог; Трезвение

## Восемь главных страстей
- Восемь главных страстей :: Корни всех грехов по учению святых отцов — прп. Иоанна Кассиана, прп. Нила Синайского, свт. Игнатия (Брянчанинова). => Чревоугодие; Гордость
- Чревоугодие :: Страсть к пище: объядение, пьянство, услаждение вкуса; врачуется воздержанием и постом. => Воздержание; Пост
- Блуд :: Плотская нечистота в делах, словах и помыслах; врачуется целомудрием. [[1 Кор 6:18]] => Целомудрие
- Сребролюбие :: Любовь к деньгам и стяжанию — «корень всех зол»; врачуется нестяжанием. [[1 Тим 6:10]] => Нестяжание
- Гнев :: Раздражительность, злопамятство, ненависть; врачуется кротостью. [[Иак 1:20]] => Кротость
- Печаль :: Греховное уныние сердца от неудач и обид мира сего; противоположна печали по Богу. [[2 Кор 7:10]] => Плач
- Уныние :: Леность к доброму делу и молитве, расслабление души, отчаяние; врачуется трезвением и терпением. => Трезвение; Отчаяние
- Тщеславие :: Искание славы человеческой; врачуется смирением. [[Ин 5:44]] => Смирение; Гордость
- Гордость :: Превозношение над ближними и противление Богу — начало всякого греха; врачуется смирением. [[Притч 16:18]] => Смирение; Падение ангелов
- Отчаяние :: Утрата надежды на милосердие Божие — тяжкий грех против надежды. => Надежда
