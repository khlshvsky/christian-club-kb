## Природа человека
- Образ Божий :: Богоподобные свойства души человека — ум, свободная воля, бессмертие, способность к любви; дарован при сотворении. [[Быт 1:26-27]] => Подобие Божие; Душа
- Подобие Божие :: Уподобление Богу в добродетели и святости, к которому человек призван возрастать действием благодати. [[Мф 5:48]] => Образ Божий; Обожение
- Душа :: Бессмертное разумное начало, вдунутое Богом в человека; по душе человек — образ Божий. [[Быт 2:7]] => Бессмертие души; Дух (в человеке)
- Тело :: Вещественная часть человеческого естества, созданная из праха; призвано быть храмом Духа Святого и воскреснет. [[1 Кор 6:19]] => Воскресение мёртвых
- Дух (в человеке) :: Высшая сторона души, обращённая к Богу: богопознание, совесть, страх Божий. [[1 Фес 5:23]] => Ум (нус); Совесть
- Ум (нус) {νοῦς} :: По святым отцам — высшая сила души, «око души», способная к созерцанию Бога. => Умная молитва; Сердце
- Сердце :: В Писании и аскетике — средоточие всей духовной жизни человека. [[Притч 4:23]] => Ум (нус); Умная молитва
- Свобода воли :: Дар Божий: способность самостоятельно избирать добро или зло; не отнимается и благодатью. [[Втор 30:19]] => Синергия; Образ Божий
- Бессмертие души :: Душа не умирает с телом и продолжает бытие после смерти. [[Мф 10:28]] => Смерть; Частный суд
- Совесть :: Внутренний нравственный закон, свидетельствующий о добре и зле; «глас Божий» в человеке. [[Рим 2:15]] => Естественный закон
- Происхождение душ :: Вопрос о том, как получает душу каждый человек; Церковь отвергла предсуществование душ (оригенизм); подробности остаются богословским мнением. => Оригенизм; Богословское мнение

## Первозданный человек
- Адам :: Первый человек, созданный Богом из праха и одушевлённый дыханием жизни; родоначальник рода человеческого. [[Быт 2:7]] => Ева; Новый Адам
- Ева :: Первая жена, созданная из ребра Адама; «мать всех живущих». [[Быт 2:22]] => Адам
- Рай :: Сад в Едеме, где жили первозданные люди в общении с Богом; также образ блаженства праведных. [[Быт 2:8]] => Царство Небесное
- Древо жизни :: Райское древо, вкушение от которого поддерживало бы бессмертие тела. [[Быт 2:9]] => Древо познания добра и зла
- Древо познания добра и зла :: Древо, вкушать от которого Бог запретил, чтобы человек утверждался в добре послушанием. [[Быт 2:17]] => Грехопадение; Послушание
- Первозданное состояние :: Состояние Адама до падения: чистый ум, согласная с Богом воля, бессмертие и господство над природой. => Образ Божий; Грехопадение
- Брак в раю :: Союз мужа и жены благословлён Богом изначально: «и будут два одна плоть». [[Быт 2:24]] => Брак
