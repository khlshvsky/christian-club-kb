## Природа Церкви
- Церковь {ἐκκλησία} :: От Бога установленное общество человеков, соединённых православной верой, законом Божиим, священноначалием и Таинствами (Катихизис). [[Мф 16:18]] => Тело Христово; Свойства Церкви
- Тело Христово :: Церковь — Тело, Глава которого Христос, а члены — верующие. [[Еф 1:22-23]] => Глава Церкви; Евхаристия
- Глава Церкви :: Единственная Глава Церкви — Господь Иисус Христос. [[Кол 1:18]] => Тело Христово; Папизм
- Церковь воинствующая :: Церковь на земле, ведущая подвиг против греха и зла. => Церковь торжествующая
- Церковь торжествующая :: Церковь небесная — святые и праведники, пребывающие с Богом; с земной Церковью составляет одно Тело. [[Евр 12:22-23]] => Церковь воинствующая; Святые
- Невеста Христова :: Образ Церкви как Невесты Агнца. [[Еф 5:25-27]] => Брак
- Столп и утверждение истины :: Слова апостола о Церкви, хранящей истину неповреждённой. [[1 Тим 3:15]] => Непогрешимость Церкви
- Непогрешимость Церкви :: Церковь в целом, руководимая Духом Святым, неуклонно хранит истину; врата ада не одолеют её. [[Мф 16:18]] => Вселенские Соборы; Соборность
- Соборность :: Единство Церкви во Христе, при котором истина хранится всей полнотой Церкви и выражается Соборами. => Кафоличность; Вселенские Соборы
- Православие {ὀρθοδοξία} :: «Правая слава» — истинная вера и правое богопочитание, хранимые Церковью. => Церковь; Торжество Православия

## Свойства Церкви
- Свойства Церкви :: По Символу веры Церковь — Единая, Святая, Соборная и Апостольская. => Единство Церкви; Святость Церкви; Кафоличность; Апостольство Церкви
- Единство Церкви :: Церковь одна, ибо один Господь, одна вера, одно Крещение. [[Еф 4:4-5]] => Свойства Церкви; Раскол
- Святость Церкви :: Церковь свята, ибо освящается Христом и Духом Святым, Таинствами и учением. [[Еф 5:26]] => Свойства Церкви
- Кафоличность :: «Соборность» — Церковь не ограничена местом, временем и народом и обладает полнотой истины и благодати. => Соборность; Свойства Церкви
- Апостольство Церкви :: Церковь хранит учение и преемство рукоположения от апостолов. [[Еф 2:20]] => Апостольское преемство

## Священноначалие
- Священноначалие (иерархия) :: Установленные Богом степени священства: епископ, пресвитер, диакон. => Епископ; Пресвитер; Диакон
- Апостольское преемство :: Непрерывная передача благодати священства от апостолов через епископское рукоположение. [[2 Тим 1:6]] => Хиротония; Епископ
- Епископ {ἐπίσκοπος} :: «Надзиратель» — высшая степень священства; преемник апостолов, совершающий все Таинства, в том числе рукоположение. [[Тит 1:5]] => Архиерей; Епархия
- Архиерей :: Общее название епископов (патриарх, митрополит, архиепископ, епископ). => Епископ
- Пресвитер (священник) :: Вторая степень священства; совершает Таинства, кроме Священства и освящения мира. => Иерей; Священство
- Иерей :: Священник; старший иерей — протоиерей, монашествующий — иеромонах. => Пресвитер (священник)
- Диакон {διάκονος} :: «Служитель» — первая степень священства; служит при совершении Таинств, но не совершает их. [[Деян 6:5-6]] => Священноначалие (иерархия)
- Причт :: Священнослужители и церковнослужители одного храма. => Клирик
- Клирик :: Член клира — священнослужитель или церковнослужитель (чтец, певец, иподиакон). => Миряне
- Миряне :: Члены Церкви, не принадлежащие к клиру; «царственное священство». [[1 Пет 2:9]] => Клирик
- Патриарх :: Первоиерарх Поместной Церкви с патриаршим устройством. => Патриархат; Пентархия
- Митрополит :: Архиерей, возглавляющий митрополию — область из нескольких епархий; также почётный титул. => Архиерей
- Предстоятель :: Глава автокефальной Церкви. => Автокефалия

## Устройство Церкви
- Поместная Церковь :: Самостоятельная (автокефальная) часть Вселенской Церкви, единая с другими в вере и Таинствах. => Автокефалия
- Автокефалия {αὐτοκεφαλία} :: «Самовозглавие» — каноническая независимость Поместной Церкви в управлении. => Поместная Церковь; Автономия
- Автономия :: Самоуправление части Церкви, зависящей от автокефальной Церкви-матери. => Автокефалия
- Патриархат :: Поместная Церковь, возглавляемая патриархом. => Патриарх
- Пентархия :: Древний порядок пяти патриарших кафедр: Рим, Константинополь, Александрия, Антиохия, Иерусалим. => Патриарх
- Диптих :: Принятый порядок поминовения предстоятелей Поместных Церквей. => Поместная Церковь
- Епархия :: Церковная область, управляемая епископом. => Епископ; Приход
- Приход :: Община верующих при храме в составе епархии. => Епархия
- Собор (церковный) :: Собрание епископов для решения вопросов веры и церковной жизни. [[Деян 15:6]] => Вселенские Соборы; Поместный Собор
- Поместный Собор :: Собор Поместной Церкви; его определения действуют в её пределах. => Собор (церковный)
- Синод :: Постоянный орган соборного управления при предстоятеле. => Собор (церковный)
- Анафема {ἀνάθεμα} :: Отлучение от Церкви упорствующих в ереси или тяжком грехе; свидетельство, что человек вне церковного общения. [[Гал 1:8]] => Ересь
- Отлучение :: Лишение права причащаться Святых Таин на время покаяния или вовсе. => Епитимия; Анафема
- Ересь {αἵρεσις} :: Сознательное и упорное отступление от догматов веры. [[Тит 3:10]] => Раскол; Анафема
- Раскол {σχίσμα} :: Отделение от церковного единства не из-за догматов, а по вопросам обрядовым или дисциплинарным. => Ересь; Единство Церкви
- Инославие :: Христианские исповедания, отделившиеся от Православной Церкви. => Раскол; Ересь
- Канон (правило) {κανών} :: Священное правило Апостолов, Соборов и святых отцов о церковной жизни. => Книга правил; Каноническое право
- Книга правил :: Собрание канонов Апостолов, Вселенских и Поместных Соборов и святых отцов. => Канон (правило)
- Номоканон (Кормчая) :: Сборник церковных правил и гражданских законов о Церкви; на Руси — Кормчая книга. => Канон (правило)
