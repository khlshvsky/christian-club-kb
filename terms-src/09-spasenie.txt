## Дело спасения
- Спасение :: Избавление человека от греха, проклятия и смерти и приобщение вечной жизни в Боге. [[Мф 1:21]] => Искупление; Обожение; Вечная жизнь
- Искупление :: Совершённое Иисусом Христом избавление рода человеческого от греха и смерти Его учением, жизнью, крестной смертью и воскресением. [[Мк 10:45]] => Искупительная жертва; Крестная смерть
- Искупительная жертва :: Жертва Христа, принесённая на кресте за грехи всего мира, однажды и навсегда. [[Евр 9:28]] => Первосвященническое служение; Евхаристия
- Примирение :: Восстановление общения человека с Богом через Христа. [[2 Кор 5:19]] => Искупление
- Усыновление :: Принятие верующих в сыны Божии по благодати через Христа. [[Гал 4:5]] => Крещение
- Обожение {θέωσις} :: Причастие человека Божественной жизни по благодати: «Бог стал человеком, чтобы человек стал богом по благодати» (свт. Афанасий Великий). [[2 Пет 1:4]] => Энергии Божественные; Подобие Божие; Благодать
- Синергия {συνέργεια} :: Соработничество благодати Божией и свободной воли человека в деле спасения. [[Флп 2:12-13]] => Благодать; Свобода воли

## Благодать и усвоение спасения
- Благодать :: Божественная сила, даруемая человеку ради заслуг Иисуса Христа, которая рождает его к новой жизни, укрепляет и освящает (Катихизис). [[Еф 2:8]] => Таинство; Обожение; Синергия
- Благодать предваряющая :: Благодать, призывающая человека к вере и покаянию прежде его обращения. [[Ин 6:44]] => Призвание
- Благодать оправдывающая :: Благодать, очищающая от грехов и возрождающая в Крещении. => Оправдание
- Благодать освящающая :: Благодать, укрепляющая в добре и возращающая в святости. => Освящение
- Призвание :: Зов Божий ко спасению, обращённый ко всем людям через проповедь Евангелия. [[1 Тим 2:4]] => Благодать предваряющая
- Обращение :: Поворот человека от греха к Богу под действием благодати. [[Деян 3:19]] => Покаяние (метанойя)
- Покаяние (метанойя) {μετάνοια} :: «Перемена ума» — сокрушение о грехах с твёрдым намерением исправить жизнь. [[Мф 4:17]] => Покаяние (Таинство); Обращение
- Оправдание :: Прощение грехов и принятие человека в благодатное общение с Богом ради Христа через живую веру, действующую любовью. [[Гал 5:6]] => Вера; Добрые дела
- Освящение :: Постепенное возрастание в святости по благодати Духа Святого. [[1 Фес 4:3]] => Святость
- Добрые дела :: Плоды живой веры; вера без дел мертва. [[Иак 2:17]] => Вера; Оправдание
- Предведение :: Бог от вечности знает свободные действия людей, не принуждая их. [[Рим 8:29]] => Предопределение
- Предопределение :: Бог предопределил ко спасению тех, о ком предвидел, что они свободно примут благодать; безусловное предопределение отвергается (Катихизис). [[Рим 8:29-30]] => Предведение; Кальвинизм
- Святость :: Причастность святости Божией, стяжаемая благодатью и подвигом; призвание всех христиан. [[1 Пет 1:15]] => Святые; Освящение
- Вечная жизнь :: Блаженная жизнь в общении с Богом, начинающаяся уже здесь в Церкви и открывающаяся в полноте в Царстве Небесном. [[Ин 17:3]] => Царство Небесное
