## Таинства вообще
- Таинство {μυστήριον} :: Священное действие, через которое под видимым образом сообщается верующим невидимая благодать Божия (Катихизис). => Семь Таинств; Благодать
- Семь Таинств :: Крещение, Миропомазание, Причащение, Покаяние, Священство, Брак, Елеосвящение. => Крещение; Миропомазание; Евхаристия; Покаяние (Таинство); Священство; Брак; Елеосвящение
- Священнодействие :: Освящение, установленное Церковью (освящение воды, храма, дома), не относящееся к семи Таинствам. => Великое освящение воды; Треба
- Треба :: Священнодействие, совершаемое по нуждам верующих (молебен, панихида, освящение жилища). => Требник; Молебен; Панихида

## Крещение
- Крещение :: Таинство, в котором верующий при троекратном погружении в воду с призыванием Отца, и Сына, и Святого Духа умирает для жизни плотской и возрождается от Духа Святого в жизнь духовную (Катихизис). [[Ин 3:5]] => Миропомазание; Прародительский грех
- Оглашение :: Научение вере готовящихся ко Крещению. => Оглашенные
- Оглашенные :: Готовящиеся ко Крещению; для них — «литургия оглашенных». => Литургия оглашенных
- Восприемник (крёстный) :: Поручитель за веру крещаемого, особенно младенца, обязанный наставлять его в вере. => Крещение
- Заклинательные молитвы :: Молитвы перед Крещением, изгоняющие диавола от крещаемого. => Отречение от сатаны
- Отречение от сатаны :: Обет крещаемого: отрекаюсь от сатаны и сочетаюсь Христу. => Крещение
- Крещение младенцев :: Древняя практика Церкви: младенцы крестятся по вере родителей и восприемников. [[Деян 16:15]] => Крещение; Восприемник (крёстный)

## Миропомазание
- Миропомазание :: Таинство, в котором верующему при помазании освящённым миром частей тела во имя Святого Духа подаются дары Святого Духа, возращающие и укрепляющие в жизни духовной (Катихизис). => Святое миро; Дары Святого Духа
- Святое миро :: Благовонное масло, освящаемое предстоятелем Церкви в Великий четверг. [[1 Ин 2:20]] => Миропомазание
- Печать дара Духа Святого :: Слова, произносимые при помазании миром. => Миропомазание

## Евхаристия
- Евхаристия {εὐχαριστία} :: «Благодарение» — Таинство Тела и Крови Христовых, центр жизни Церкви. => Причащение; Божественная литургия
- Причащение :: Таинство, в котором верующий под видом хлеба и вина вкушает самое Тело и Кровь Христовы для вечной жизни (Катихизис). [[Ин 6:53-56]] => Евхаристия; Святые Дары
- Святые Дары :: Хлеб и вино, преложенные в Тело и Кровь Христовы. => Преложение
- Преложение {μεταβολή} :: Изменение хлеба и вина в истинное Тело и Кровь Христовы действием Духа Святого. => Пресуществление; Эпиклеза
- Пресуществление {μετουσίωσις} :: Термин Послания восточных патриархов (1723) и Катихизиса: хлеб и вино прелагаются в самое Тело и Кровь, сохраняя лишь видимый образ; образ преложения непостижим. => Преложение
- Эпиклеза {ἐπίκλησις} :: Призывание Духа Святого на Дары в анафоре: «Ниспосли Духа Твоего Святаго…». => Анафора; Преложение
- Анафора {ἀναφορά} :: Евхаристический канон — главная молитва Литургии, во время которой совершается Таинство. => Эпиклеза; Божественная литургия
- Агнец (литургический) :: Часть просфоры, вынимаемая на проскомидии и прелагаемая в Тело Христово. => Проскомидия; Просфора
- Запричастный стих :: Песнопение, исполняемое во время причащения священнослужителей. => Божественная литургия
- Приготовление к Причастию :: Пост, молитва, исповедь и примирение с ближними перед Причащением. [[1 Кор 11:28]] => Говение; Исповедь
- Говение :: Подготовка ко Причастию постом, усиленной молитвой и посещением богослужений. => Приготовление к Причастию

## Покаяние
- Покаяние (Таинство) :: Таинство, в котором исповедующий грехи при видимом изъявлении прощения от священника невидимо разрешается от грехов Самим Иисусом Христом (Катихизис). [[Ин 20:22-23]] => Исповедь; Епитимия
- Исповедь :: Устное исповедание грехов перед священником в Таинстве Покаяния. [[1 Ин 1:9]] => Покаяние (Таинство)
- Разрешительная молитва :: Молитва священника, которой разрешаются грехи кающегося. => Покаяние (Таинство)
- Епитимия {ἐπιτιμία} :: Духовное врачевство — подвиг молитвы, поста или милосердия, назначаемый кающемуся для исцеления. => Покаяние (Таинство)
- Духовник :: Священник, принимающий исповедь и руководящий духовной жизнью. => Старчество

## Священство, Брак, Елеосвящение
- Священство :: Таинство, в котором Дух Святой правильно избранного через святительское рукоположение поставляет совершать Таинства и пасти стадо Христово (Катихизис). => Хиротония; Священноначалие (иерархия)
- Хиротония {χειροτονία} :: Рукоположение в священную степень (епископа, пресвитера, диакона) в алтаре за Литургией. [[1 Тим 4:14]] => Хиротесия; Священство
- Хиротесия {χειροθεσία} :: Возложение рук при поставлении в церковнослужители (чтец, иподиакон) и в церковные звания. => Хиротония
- Брак :: Таинство, в котором при свободном обещании жениха и невесты о взаимной верности благословляется их союз в образ духовного союза Христа с Церковью (Катихизис). [[Еф 5:31-32]] => Венчание; Брак в раю
- Венчание :: Чинопоследование Таинства Брака с возложением венцов. => Брак
- Обручение :: Часть чина Брака: обмен кольцами как знак взаимного обещания. => Венчание
- Елеосвящение :: Таинство, в котором при помазании тела елеем призывается на больного благодать Божия, исцеляющая немощи душевные и телесные (Катихизис). [[Иак 5:14-15]] => Соборование
- Соборование :: Народное название Елеосвящения, совершаемого собором (по уставу — семью) священников. => Елеосвящение
