## Подвиг
- Аскетика {ἄσκησις} :: Учение о духовном подвиге — борьбе со страстями и стяжании добродетелей. => Подвиг; Невидимая брань
- Подвиг :: Усилие человека в исполнении заповедей, без которого благодать не усваивается. [[Мф 11:12]] => Синергия
- Трезвение {νῆψις} :: Внимательное хранение ума и сердца от греховных помыслов. [[1 Пет 5:8]] => Помысл; Добротолюбие
- Рассуждение :: Дар различать добро и зло, духов и помыслы; по отцам — высшая из добродетелей. => Духовная прелесть
- Духовная прелесть :: Самообольщение — принятие ложного за истинное в духовной жизни из гордости. => Рассуждение; Гордость
- Бесстрастие :: Свобода от страстей, достигаемая благодатью и подвигом; не бесчувственность, а чистота любви. => Страсть; Обожение
- Исихазм {ἡσυχία} :: «Безмолвие» — традиция умной молитвы и созерцания, богословски обоснованная свт. Григорием Паламой. => Иисусова молитва; Фаворский свет; Паламизм
- Паламизм :: Учение свт. Григория Паламы о различии сущности и нетварных энергий Божиих; принято Церковью. => Энергии Божественные; Григорий Палама
- Добротолюбие :: Собрание аскетических творений отцов, составленное прп. Никодимом Святогорцем и свт. Макарием Коринфским; на славянский переведено прп. Паисием Величковским. => Трезвение; Исихазм
- Память смертная :: Постоянное памятование о смерти и суде как средство против греха. [[Сир 7:39]] => Смерть

## Монашество
- Монашество :: Особый путь жизни по обетам девства, нестяжания и послушания ради всецелого посвящения Богу. [[Мф 19:21]] => Монашеские обеты; Преподобные
- Монашеские обеты :: Обеты девства (целомудрия), нестяжания и послушания. => Монашество
- Постриг :: Чин вступления в монашество с изменением имени. => Монашество
- Рясофор :: Первая ступень монашества. => Постриг
- Мантия (малая схима) :: Монашество с принесением основных обетов. => Постриг
- Великая схима :: Высшая степень монашества — ангельский образ. => Постриг
- Лавра :: Большой и значимый монастырь (Троице-Сергиева, Киево-Печерская). => Монастырь
- Монастырь :: Община монахов или монахинь, живущих по уставу. => Монашество
- Скит :: Небольшое монашеское поселение для уединённой жизни. => Монастырь
- Старчество :: Духовное руководство опытного подвижника; знаменито в Оптиной пустыни. => Духовник; Послушание
- Игумен :: Настоятель монастыря. => Монастырь
- Архимандрит :: Высший сан монашествующего священника. => Игумен
- Иеромонах :: Монах в сане священника. => Иерей
- Иеродиакон :: Монах в сане диакона. => Диакон
- Белое духовенство :: Женатое духовенство (не принявшее монашества). => Чёрное духовенство
- Чёрное духовенство :: Монашествующее духовенство; из него избираются епископы. => Белое духовенство; Епископ
