## Пасха и двунадесятые праздники
- Пасха :: Светлое Христово Воскресение — праздник праздников и торжество из торжеств; день его исчисляется по пасхалии. [[1 Кор 5:7]] => Воскресение Христово; Пасхалия; Светлая седмица
- Двунадесятые праздники :: Двенадцать великих праздников Господских и Богородичных, кроме Пасхи. => Рождество Пресвятой Богородицы; Рождество Христово; Пятидесятница
- Рождество Пресвятой Богородицы :: 8 (21) сентября — рождение Девы Марии от праведных Иоакима и Анны. => Двунадесятые праздники; Богородица
- Воздвижение Креста Господня :: 14 (27) сентября — обретение и воздвижение Креста в Иерусалиме (IV в.). => Крест; Двунадесятые праздники
- Введение во храм Пресвятой Богородицы :: 21 ноября (4 декабря) — посвящение отроковицы Марии Богу в Иерусалимском храме. => Двунадесятые праздники
= Рождество Христово
= Крещение Господне
- Сретение Господне :: 2 (15) февраля — встреча Младенца Христа в храме праведным Симеоном. [[Лк 2:28-32]] => Двунадесятые праздники
- Благовещение :: 25 марта (7 апреля) — благая весть Архангела Гавриила Деве Марии о воплощении Сына Божия. [[Лк 1:26-38]] => Гавриил архангел; Боговоплощение
- Вход Господень в Иерусалим :: Вербное воскресенье — за неделю до Пасхи. [[Ин 12:12-13]] => Страстная седмица
= Вознесение Господне
- Пятидесятница :: День Святой Троицы — пятидесятый день по Пасхе, память сошествия Святого Духа. => Сошествие Святого Духа
= Преображение Господне
- Успение Пресвятой Богородицы :: 15 (28) августа — блаженная кончина Богородицы и, по Преданию, взятие Её с телом на небо. => Богородица; Успенский пост

## Великие праздники
- Покров Пресвятой Богородицы :: 1 (14) октября — явление Богородицы во Влахернском храме в Константинополе (X в.). => Ходатайство Богородицы
- Обрезание Господне :: 1 (14) января — восьмой день по Рождеству. [[Лк 2:21]] => Рождество Христово
- Рождество Иоанна Предтечи :: 24 июня (7 июля). => Иоанн Предтеча
- Усекновение главы Иоанна Предтечи :: 29 августа (11 сентября) — однодневный строгий пост. [[Мк 6:27]] => Иоанн Предтеча
- Память апостолов Петра и Павла :: 29 июня (12 июля) — завершение Петрова поста. => Петров пост
- Иоанн Предтеча :: Креститель Господень, последний пророк Ветхого Завета, «больший из рождённых жёнами». [[Мф 11:11]] => Крещение Господне
- Великое освящение воды :: Чин освящения воды в Крещенский сочельник и в Богоявление. => Святая вода

## Подвижные дни
- Страстная седмица :: Последняя неделя перед Пасхой, посвящённая воспоминанию страданий, смерти и погребения Христа. => Великий четверг; Великая пятница
- Великий четверг :: Воспоминание Тайной вечери и установления Евхаристии. [[Лк 22:19-20]] => Евхаристия; Тайная вечеря
- Великая пятница :: День крестных страданий и смерти Спасителя; вынос Плащаницы. => Плащаница; Крестная смерть
- Тайная вечеря :: Последняя трапеза Христа с учениками, на которой Он установил Таинство Евхаристии. [[Мф 26:26-28]] => Евхаристия
- Светлая седмица :: Неделя после Пасхи, празднуемая как единый день. => Пасха
- Неделя :: Церковное название воскресного дня. => Седмичный круг
- Родительские субботы :: Дни особого поминовения усопших. => Поминовение усопших

## Посты
- Пост :: Воздержание от скоромной пищи, соединённое с молитвой, покаянием и делами милосердия. [[Мф 6:16-18]] => Великий пост; Воздержание
- Великий пост :: Святая Четыредесятница — сорок дней и Страстная седмица перед Пасхой. [[Мф 4:2]] => Триодь; Пост
- Рождественский пост :: Сорокадневный пост перед Рождеством Христовым (с 15 (28) ноября). => Пост
- Петров пост :: Апостольский пост от Недели всех святых до 29 июня (12 июля). => Пост
- Успенский пост :: Пост с 1 (14) по 14 (27) августа перед Успением. => Пост
- Однодневные посты :: Среда и пятница всего года (кроме сплошных седмиц), Крещенский сочельник, Усекновение, Воздвижение. => Пост
- Сплошная седмица :: Неделя, в которую отменяется пост в среду и пятницу (Святки, Светлая седмица и др.). => Пост
- Скоромная пища :: Пища животного происхождения (мясо, молочные продукты, яйца), запрещённая в пост. => Пост
