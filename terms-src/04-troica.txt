## Основные понятия
- Святая Троица {Τριάς} :: Бог един по существу и троичен в Лицах: Отец, Сын и Святой Дух — Троица единосущная и нераздельная. [[Мф 28:19]] => Ипостась; Единосущие; Единство Божие
- Ипостась {ὑπόστασις} :: Лицо в Боге; в Троице три Ипостаси, единые по сущности и различаемые личными свойствами. => Лицо; Сущность; Личные свойства
- Лицо {πρόσωπον} :: То же, что Ипостась: личное бытие Отца, Сына и Святого Духа. => Ипостась
- Сущность {οὐσία} :: Общее естество Трёх Лиц; в Троице одна сущность, одна воля, одна сила и одно действие. => Ипостась; Единосущие
- Единосущие {ὁμοούσιος} :: Слово Никейского Символа: Сын одного существа с Отцом; утверждено против Ария. => Никео-Цареградский Символ веры; Арианство; I Вселенский Собор
- Личные свойства :: Свойства, отличающие Лица: Отец не рождается и не исходит; Сын рождается от Отца; Дух исходит от Отца. => Нерожденность; Рождение Сына; Исхождение Духа
- Нерожденность :: Личное свойство Бога Отца: Он ни от кого не рождается и не исходит. => Монархия Отца
- Рождение Сына :: Личное свойство Сына: Он предвечно рождается от Отца, «прежде всех век». [[Пс 2:7]] => Единородный; Сын Божий
- Исхождение Духа :: Личное свойство Духа: Он предвечно исходит от Отца. [[Ин 15:26]] => Дух Святой; Филиокве
- Монархия Отца {μοναρχία} :: Отец — единое начало (источник) Божества Сына и Духа; основание единства Троицы. => Нерожденность; Филиокве
- Перихоресис {περιχώρησις} :: Взаимопроникновение Лиц Троицы: Отец в Сыне, Сын в Отце, без слияния. [[Ин 14:10]] => Святая Троица
- Неслиянность и нераздельность :: Лица Троицы не сливаются друг с другом и не разделяются по существу. => Савеллианство; Тритеизм
- Троичность в Ветхом Завете :: Указания на тайну Троицы: «Сотворим человека…», явление трёх странников Аврааму, Трисвятое серафимов. [[Быт 1:26]] [[Быт 18:1-3]] => Элохим; Троица ветхозаветная (икона)

## Лица Святой Троицы
- Бог Отец :: Первое Лицо Святой Троицы, безначальный Отец, рождающий Сына и изводящий Духа. => Нерожденность; Отец
- Сын Божий :: Второе Лицо Святой Троицы, предвечно рождённый от Отца, ради нас вочеловечившийся. [[Ин 1:18]] => Логос; Единородный; Иисус Христос
- Логос {Λόγος} :: «Слово» — имя Сына Божия: Он есть Слово Отца, Им всё сотворено. [[Ин 1:1-3]] => Сын Божий; Премудрость Божия
- Единородный :: Наименование Сына: Он один рождён от сущности Отца. [[Ин 1:14]] => Рождение Сына
- Дух Святой :: Третье Лицо Святой Троицы, Господь Животворящий, исходящий от Отца, Которому поклоняются и Которого славят со Отцом и Сыном. => Исхождение Духа; Утешитель

## Исповедание и споры
- Никео-Цареградский Символ веры :: Символ, принятый на I (325) и II (381) Вселенских Соборах; неизменно читается за Литургией и при Крещении. => Символ веры; Филиокве
- Каппадокийское богословие :: Учение свт. Василия Великого, Григория Богослова и Григория Нисского, различившее понятия сущности и ипостаси. => Великие каппадокийцы; Ипостась
- Троица ветхозаветная (икона) :: Иконографический образ Святой Троицы в виде трёх Ангелов у Авраама; классический образец — икона прп. Андрея Рублёва. [[Быт 18:1-2]] => Икона; Андрей Рублёв
! Тритеизм :: Заблуждение, разделявшее Троицу на трёх богов; отвергнуто Церковью. => Неслиянность и нераздельность
