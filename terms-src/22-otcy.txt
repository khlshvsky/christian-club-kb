## Понятия
- Святые отцы :: Святые учители Церкви, отличавшиеся православием, святостью жизни и признанием Церкви. => Согласие отцов; Патрология
- Учитель Церкви :: Наставник веры, чьё учение Церковь признаёт верным; в патрологии так же называют древних церковных писателей, не прославленных в лике святых, — их отдельные мнения Церковь не приняла. => Святые отцы
- Мужи апостольские :: Ученики апостолов: свв. Климент Римский, Игнатий Богоносец, Поликарп Смирнский. => Апостольский век
- Апологеты :: Защитники веры II–III вв.: св. Иустин Философ, Афинагор и др. => Апологетика
- Великие каппадокийцы :: Свт. Василий Великий, Григорий Богослов и Григорий Нисский. => Каппадокийское богословие
- Три святителя :: Свт. Василий Великий, Григорий Богослов и Иоанн Златоуст; общая память 30 января (12 февраля). => Василий Великий; Иоанн Златоуст

## Святые отцы
- Игнатий Богоносец :: Священномученик, епископ Антиохийский (†107), ученик апостола Иоанна. => Мужи апостольские
- Ириней Лионский :: Священномученик (II в.), обличитель гностицизма. => Гностицизм
- Афанасий Великий :: Свт. архиепископ Александрийский (IV в.), столп Православия против ариан. => Арианство; Обожение
- Василий Великий :: Свт. архиепископ Кесарии Каппадокийской (IV в.), автор Литургии и «Шестоднева». => Великие каппадокийцы; Шестоднев
- Григорий Богослов :: Свт. архиепископ Константинопольский (IV в.), прозванный Богословом за слова о Троице. => Великие каппадокийцы
- Григорий Нисский :: Свт. епископ Нисский (IV в.), брат свт. Василия. => Великие каппадокийцы
- Иоанн Златоуст :: Свт. архиепископ Константинопольский (IV–V вв.), великий проповедник и толкователь Писания. => Литургия свт. Иоанна Златоуста
- Кирилл Александрийский :: Свт. архиепископ (V в.), защитник именования Богородица на III Вселенском Соборе. => III Вселенский Собор
- Дионисий Ареопагит :: Ученик ап. Павла; под его именем дошли творения о небесной и церковной иерархии. => Небесная иерархия
- Максим Исповедник :: Прп. (VII в.), исповедник двух воль во Христе. => Монофелитство
- Иоанн Лествичник :: Прп. игумен Синайский (VII в.), автор «Лествицы». => Прилог
- Иоанн Дамаскин :: Прп. (VIII в.), автор «Точного изложения православной веры», защитник икон. => Иконопочитание
- Симеон Новый Богослов :: Прп. (X–XI вв.), учитель о видении Божественного света. => Фаворский свет
- Григорий Палама :: Свт. архиепископ Фессалоникийский (XIV в.), богослов исихазма. => Паламизм
- Марк Эфесский :: Свт. (XV в.), единственный не подписавший Флорентийскую унию. => Флорентийская уния

## Русские святые и богословы
- Кирилл и Мефодий :: Равноапостольные учители словенские (IX в.), создатели славянской письменности. => Церковнославянская Библия
- Сергий Радонежский :: Прп. игумен (XIV в.), основатель Троице-Сергиевой лавры. => Лавра
- Андрей Рублёв :: Прп. иконописец (XIV–XV вв.), автор иконы «Троица». => Троица ветхозаветная (икона)
- Нил Сорский :: Прп. (XV–XVI вв.), учитель скитского безмолвия. => Скит
- Серафим Саровский :: Прп. (XVIII–XIX вв.), учитель о стяжании Духа Святого. => Стяжание Духа Святого
- Филарет (Дроздов) :: Свт. митрополит Московский (XIX в.), автор Пространного катихизиса. => Катихизис
- Филарет (Гумилевский) :: Свт. архиепископ Черниговский (XIX в.), автор «Православного догматического богословия». => Догматическое богословие
- Игнатий Брянчанинов :: Свт. (XIX в.), аскетический писатель. => Восемь главных страстей
- Феофан Затворник :: Свт. (XIX в.), переводчик «Добротолюбия» на русский язык, учитель молитвы. => Добротолюбие
- Тихон Московский :: Свт. патриарх (1917–1925), исповедник. => Поместный Собор 1917–1918 гг.
- Катихизис {κατήχησις} :: «Оглашение» — изложение православной веры для наставления; Пространный катихизис свт. Филарета (Дроздова). => Оглашение; Символ веры
