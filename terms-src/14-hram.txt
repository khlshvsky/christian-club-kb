## Устройство храма
- Храм :: Освящённое здание для богослужения и совершения Таинств — «дом Божий». => Алтарь; Иконостас; Притвор
- Алтарь :: Восточная, самая святая часть храма, отделённая иконостасом; образ неба. => Престол; Жертвенник; Горнее место
- Престол :: Освящённый стол в середине алтаря, на котором совершается Евхаристия; место особого присутствия Божия. => Антиминс; Алтарь
- Жертвенник :: Стол в северной части алтаря, на котором совершается проскомидия. => Проскомидия
- Горнее место :: Возвышение у восточной стены алтаря — место архиерея; образ небесного престола. => Алтарь
- Иконостас :: Стена с иконами, отделяющая алтарь от средней части храма. => Царские врата; Икона
- Царские врата :: Средние врата иконостаса, через которые выносятся Святые Дары. => Иконостас
- Солея :: Возвышение перед иконостасом. => Амвон
- Амвон :: Выступ солеи против Царских врат, с которого читается Евангелие и произносится проповедь. => Солея
- Клирос :: Место для певцов и чтецов у иконостаса. => Солея
- Притвор :: Западная часть храма, вход; в древности — место оглашенных и кающихся. => Оглашенные
- Антиминс {ἀντιμήνσιον} :: Освящённый архиереем плат с изображением положения во гроб и частицей мощей; без него не совершается Литургия. => Престол; Мощи
- Освящение храма :: Чин, которым храм посвящается Богу и делается местом совершения Таинств. => Храм; Антиминс

## Утварь
- Потир :: Чаша, в которой на Литургии прелагается вино в Кровь Христову. => Евхаристия
- Дискос :: Блюдо на подножии, на котором полагается Агнец. => Агнец (литургический)
- Звездица :: Две скреплённые дуги над дискосом, напоминающие о Вифлеемской звезде. => Дискос
- Лжица :: Ложечка для причащения мирян. => Причащение
- Копие :: Нож в форме копья для приготовления Агнца на проскомидии. => Проскомидия
- Просфора {προσφορά} :: «Приношение» — круглый квасной хлеб с печатью для проскомидии. => Проскомидия; Опресноки
- Кадило :: Сосуд для каждения ладаном — знак молитвы и благоговения. [[Пс 140:2]] => Богослужение
- Лампада :: Светильник перед иконой — знак горения веры и молитвы. => Икона
- Плащаница :: Плат с изображением Христа во гробе, выносимый в Великую пятницу. => Страстная седмица

## Облачения
- Облачения :: Священные одежды священнослужителей, соответствующие степени священства. => Стихарь; Фелонь; Саккос
- Подрясник :: Нижняя длиннополая одежда священнослужителей. => Ряса
- Ряса :: Верхняя одежда клириков и монахов с широкими рукавами. => Подрясник
- Стихарь :: Длинная одежда диакона и церковнослужителей — знак чистоты души. => Облачения
- Орарь :: Длинная лента на плече диакона — образ ангельских крыл. => Диакон
- Поручи :: Нарукавники священнослужителей — знак силы Божией, действующей их руками. => Облачения
- Епитрахиль :: Лента на шее священника, без которой он не совершает богослужения; знак благодати священства. => Пресвитер (священник)
- Пояс :: Знак готовности к служению. => Облачения
- Фелонь :: Верхнее облачение священника — образ багряницы Христовой. => Пресвитер (священник)
- Омофор :: Широкая лента на плечах архиерея — образ заблудшей овцы, взятой на рамена Пастыря. [[Лк 15:5]] => Епископ
- Саккос :: Верхнее облачение архиерея. => Епископ
- Митра :: Головной убор архиерея (и заслуженных священников). => Архиерей
- Панагия :: «Всесвятая» — образок Богородицы на груди архиерея. => Архиерей
- Наперсный крест :: Крест, носимый на груди священником. => Пресвитер (священник)
