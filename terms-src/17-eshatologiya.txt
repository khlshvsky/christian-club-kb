## Частная эсхатология
- Эсхатология {ἔσχατα} :: Учение о последних судьбах человека и мира. => Частный суд; Второе пришествие
- Частный суд :: Суд над душой человека после смерти, определяющий её состояние до всеобщего суда. [[Евр 9:27]] => Страшный суд
- Мытарства :: Распространённый в святоотеческой и житийной письменности образ испытания души после смерти; Церковь не определяет его догматически, но понимает как духовную реальность частного суда. => Частный суд
- Поминовение усопших :: Молитвы, Литургия и милостыня об усопших, приносящие им облегчение. => Панихида; Родительские субботы
- Третий, девятый и сороковой дни :: Дни особого поминовения усопшего по церковному обычаю. => Поминовение усопших
- Промежуточное состояние :: Состояние душ между смертью и всеобщим воскресением: праведники предвкушают блаженство, грешники — мучения. => Частный суд; Лоно Авраамово
- Лоно Авраамово :: Образ блаженного упокоения праведных. [[Лк 16:22]] => Рай

## Общая эсхатология
- Второе пришествие :: Явление Христа во славе для суда над живыми и мёртвыми в конце мира. [[Мф 24:30]] => Страшный суд; Антихрист
- Знамения последних времён :: Предвестия Второго пришествия: проповедь Евангелия всем народам, оскудение веры и любви, явление антихриста. [[Мф 24:14]] => Второе пришествие
- Антихрист :: Противник Христа, который явится перед концом мира и будет искать поклонения себе. [[2 Фес 2:3-4]] => Второе пришествие; Апокалипсис
- Воскресение мёртвых :: Всеобщее воскресение тел перед Страшным судом; тела праведных будут нетленными и духовными. [[1 Кор 15:42-44]] => Воскресение Христово; Тело
- Страшный суд :: Всеобщий суд Христов над всеми людьми при Втором пришествии. [[Мф 25:31-46]] => Правосудие Божие
- Конец мира :: Преображение мира огнём и явление нового неба и новой земли. [[2 Пет 3:10-13]] => Новое небо и новая земля
- Новое небо и новая земля :: Обновлённое творение, в котором обитает правда. [[Откр 21:1]] => Царство Небесное
- Царство Небесное :: Вечное блаженное Царство Божие, в котором праведники будут видеть Бога. [[Мф 25:34]] => Рай; Вечная жизнь; Царство Божие
- Царство Божие :: Царство благодати, начинающееся в Церкви, и Царство славы в будущем веке. [[Лк 17:21]] => Царство Небесное
- Боговидение :: Созерцание Бога праведниками в будущей жизни «лицем к лицу». [[1 Кор 13:12]] => Царство Небесное
- Ад (геенна) :: Место и состояние вечного мучения отвергших Бога. [[Мф 25:41]] => Вечные муки
- Вечные муки :: Нескончаемое состояние осуждённых; Церковь отвергает учение о конце мучений. [[Мф 25:46]] => Ад (геенна); Апокатастасис
