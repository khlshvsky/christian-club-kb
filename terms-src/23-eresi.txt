## Ереси о Святой Троице
! Гностицизм :: Учения II в. о спасении через тайное знание и о злом вещественном мире; обличены сщмч. Иринеем. => Ириней Лионский; Дуализм
! Савеллианство (модализм) :: Учение о Троице как о трёх образах (модусах) одного Лица; отвергнуто Церковью. => Неслиянность и нераздельность
! Монархианство :: Отрицание самостоятельности Лиц Троицы ради единства Бога. => Савеллианство (модализм)
! Арианство :: Учение Ария (IV в.) о Сыне как высшем творении, не единосущном Отцу; осуждено I Вселенским Собором. => I Вселенский Собор; Единосущие
! Полуарианство :: Учение о Сыне как «подобосущном» Отцу. => Арианство
! Духоборчество (македонианство) :: Учение Македония (IV в.) о Духе Святом как творении; осуждено II Вселенским Собором. => II Вселенский Собор
! Филиокве (Filioque) :: Латинское добавление к Символу веры «и от Сына» об исхождении Духа; отвергается Православной Церковью: Дух исходит от Отца, а посылается в мир через Сына. => Монархия Отца; Великая схизма

## Ереси о Лице Христа
! Аполлинарианство :: Учение о том, что место человеческого ума во Христе занимало Божество; осуждено II Вселенским Собором. => Богочеловек
! Несторианство :: Учение Нестория о двух лицах во Христе и отказ называть Деву Марию Богородицей; осуждено III Вселенским Собором. => III Вселенский Собор; Богородица
! Монофизитство :: Учение Евтихия об одном естестве во Христе, поглотившем человечество; осуждено IV Вселенским Собором. => IV Вселенский Собор; Два естества во Христе
! Монофелитство :: Учение об одной воле во Христе; осуждено VI Вселенским Собором. => VI Вселенский Собор; Две воли во Христе
! Докетизм :: Учение о призрачности тела Христова. [[1 Ин 4:2-3]] => Боговоплощение
! Адопцианство :: Учение о Христе как человеке, усыновлённом Богом. => Сын Божий

## Иные древние заблуждения
! Манихейство :: Дуалистическое учение Мани (III в.) о двух равных началах. => Дуализм
! Монтанизм :: Лжепророческое движение II в., претендовавшее на новое откровение Духа. => Сверхъестественное откровение
! Оригенизм :: Мнения последователей Оригена о предсуществовании душ и всеобщем восстановлении; осуждены V Вселенским Собором. => Апокатастасис; V Вселенский Собор
! Апокатастасис {ἀποκατάστασις} :: Учение о конечном восстановлении всех, включая бесов, и прекращении мук; осуждено Церковью. => Вечные муки; Оригенизм
! Хилиазм :: Учение о тысячелетнем земном царстве Христа до конца мира; отвергнуто Церковью. [[Откр 20:4]] => Второе пришествие
! Пелагианство :: Учение Пелагия (V в.) о спасении собственными силами без благодати; осуждено Церковью. => Благодать; Синергия
! Новатианство :: Ригористский раскол III в., отказывавший падшим в покаянии. => Покаяние (Таинство)
! Донатизм :: Раскол IV в., ставивший действительность Таинств в зависимость от личной святости совершителя. => Таинство
! Иконоборчество :: Ересь VIII–IX вв., отвергавшая почитание икон; осуждена VII Вселенским Собором. => VII Вселенский Собор; Торжество Православия
! Богомильство :: Дуалистическая ересь X–XIV вв. на Балканах. => Манихейство

## Западные отступления
! Папизм :: Учение о главенстве и непогрешимости папы Римского над всей Церковью (догмат 1870 г.); противоречит соборному устройству Церкви. => Глава Церкви; Соборность
! Чистилище :: Латинское учение о месте очистительных мук для удовлетворения правде Божией; отвергается Православной Церковью. => Частный суд; Поминовение усопших
! Индульгенции :: Латинское отпущение временных наказаний за грехи из «сокровищницы заслуг» святых. => Сверхдолжные заслуги
! Сверхдолжные заслуги :: Латинское учение о «лишних» заслугах святых, которыми может распоряжаться Церковь. => Индульгенции
! Непорочное зачатие (латинский догмат) :: Латинский догмат 1854 г. о зачатии Девы Марии свободной от первородного греха; Православная Церковь, почитая Богородицу Пречистой, этого учения не принимает. => Богородица; Прародительский грех
! Опресноки :: Употребление пресного хлеба в Евхаристии у латинян; Православная Церковь совершает её на квасном хлебе. => Просфора
! Униатство :: Подчинение части православных Риму с сохранением восточного обряда. => Флорентийская уния; Брестская уния

## Протестантизм и расколы
! Протестантизм :: Исповедания, возникшие в XVI в. при отделении от Рима; отвергают Предание, большинство Таинств, иконы и молитву святым. => Sola Scriptura; Sola fide
! Sola Scriptura :: «Только Писание» — отрицание Священного Предания. => Священное Предание
! Sola fide :: «Только вера» — отрицание значения добрых дел в спасении. => Оправдание; Добрые дела
! Кальвинизм :: Учение о безусловном предопределении одних к спасению, других — к погибели. => Предопределение
- Старообрядчество :: Движение отделившихся от Русской Церкви после реформ XVII в.; единоверие — путь воссоединения. => Церковный раскол XVII века
- Двоеперстие :: Сложение двух перстов для крестного знамения, сохраняемое старообрядцами. => Крестное знамение
! Сектантство :: Общины, отделившиеся от Церкви и проповедующие учения, противные православной вере. => Ересь
