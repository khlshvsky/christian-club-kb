## Лицо Богочеловека
- Иисус Христос :: Сын Божий, Бог истинный, ради нашего спасения вочеловечившийся; одно Лицо в двух естествах. [[Мф 16:16]] => Боговоплощение; Богочеловек; Мессия
- Иисус :: «Спаситель» (евр. Иешуа — «Бог спасает»); имя, наречённое по благовестию Ангела. [[Мф 1:21]] => Иисус Христос
- Христос {Χριστός} :: «Помазанник» (евр. Мессия); имя трёх служений — пророческого, первосвященнического и царского. => Мессия; Три служения Христа
- Мессия :: Обетованный Избавитель, Помазанник Божий, предвозвещённый пророками. [[Ин 4:25-26]] => Христос; Мессианские пророчества
- Боговоплощение :: Сын Божий воспринял от Девы Марии человеческое естество — душу и тело — и стал человеком, не перестав быть Богом. [[Ин 1:14]] => Ипостасное соединение; Богородица
- Богочеловек :: Христос — совершенный Бог и совершенный человек в единой Ипостаси. [[1 Тим 2:5]] => Два естества во Христе
- Ипостасное соединение :: Соединение Божества и человечества в единой Ипостаси Бога Слова. => Халкидонский орос; Два естества во Христе
- Два естества во Христе :: Божество и человечество во Христе соединены неслитно, неизменно, нераздельно и неразлучно. => Халкидонский орос; Монофизитство; Несторианство
- Халкидонский орос :: Вероопределение IV Вселенского Собора (451) о едином Христе в двух естествах «неслитно, неизменно, нераздельно, неразлучно». => IV Вселенский Собор; Два естества во Христе
- Две воли во Христе :: Во Христе две воли и два действия — Божеское и человеческое; человеческая воля во всём покорна Божественной (VI Вселенский Собор). [[Лк 22:42]] => Монофелитство; VI Вселенский Собор
- Общение свойств :: Свойства одного естества Христа приписываются Его единому Лицу: «Господа славы распяли», «Бог родился». [[1 Кор 2:8]] => Ипостасное соединение
- Обожение человечества Христа :: Человеческое естество Христа, не изменяясь, исполнено Божественной славы через соединение с Божеством. => Обожение; Преображение Господне
- Кенозис (истощание) {κένωσις} :: Самоуничижение Сына Божия, принявшего образ раба ради нашего спасения. [[Флп 2:7]] => Боговоплощение
- Безгрешность Христа :: Христос, подобно нам искушённый во всём, кроме греха, был совершенно свободен от греха. [[Евр 4:15]] => Новый Адам
- Новый Адам :: Христос — Глава нового, возрождённого человечества. [[1 Кор 15:45]] => Адам; Искупление
- Агнец Божий :: Имя Христа как Жертвы, взявшей на Себя грех мира. [[Ин 1:29]] => Прообраз; Агнец (литургический)
- Сын Человеческий :: Имя, которым Христос обычно называл Себя; указывает на истинное человечество и мессианское достоинство (Дан 7). [[Дан 7:13]] => Мессия

## Служения Христа
- Три служения Христа :: Пророческое, первосвященническое и царское служение Помазанника. => Пророческое служение; Первосвященническое служение; Царское служение
- Пророческое служение :: Христос возвестил людям полноту воли Божией и учение спасения. [[Ин 1:18]] => Три служения Христа
- Первосвященническое служение :: Христос принёс Себя в жертву за грехи мира и ходатайствует за нас. [[Евр 9:11-12]] => Искупительная жертва
- Царское служение :: Христос имеет всякую власть на небе и на земле; Царство Его не будет конца. [[Мф 28:18]] => Царство Божие

## Земной путь Спасителя
- Рождество Христово :: Рождение Сына Божия по плоти от Девы Марии в Вифлееме. [[Лк 2:7]] => Двунадесятые праздники; Богородица
- Крещение Господне :: Крещение Христа от Иоанна в Иордане, где явилась Святая Троица; праздник Богоявления 6 (19) января. [[Мф 3:16-17]] => Богоявление (теофания); Двунадесятые праздники
- Преображение Господне :: Явление Христом Божественной славы ученикам на горе Фавор; празднуется 6 (19) августа. [[Мф 17:1-2]] => Фаворский свет; Двунадесятые праздники
- Крестная смерть :: Добровольные страдания и смерть Христа на кресте за грехи всего мира. [[Флп 2:8]] => Искупление; Крест
- Сошествие во ад :: Христос по смерти душою сошёл во ад, проповедал там победу над смертью и вывел души ожидавших Его. [[1 Пет 3:19]] => Воскресение Христово
- Воскресение Христово :: Восстание Христа из мёртвых в третий день силою Своего Божества — основание христианской веры. [[1 Кор 15:14]] => Пасха; Воскресение мёртвых
- Вознесение Господне :: Восшествие Христа с плотию на небо в сороковой день по Воскресении; подвижный праздник. [[Деян 1:9]] => Седение одесную Отца; Двунадесятые праздники
- Седение одесную Отца :: Христос и по человечеству соучаствует в Божественной славе и власти Отца. [[Евр 1:3]] => Вознесение Господне

## Богородица
- Богородица {Θεοτόκος} :: Дева Мария, родившая по плоти Сына Божия; именование утверждено III Вселенским Собором против Нестория. => III Вселенский Собор; Несторианство; Приснодева
- Приснодева {ἀειπάρθενος} :: Мария — Дева до Рождества, в Рождестве и по Рождестве. [[Ис 7:14]] => Богородица
- Бессеменное зачатие :: Зачатие Сына Божия от Духа Святого без мужа. [[Лк 1:35]] => Благовещение
- Ходатайство Богородицы :: Богородица — первая молитвенница за род христианский, «Честнейшая херувим». => Покров Пресвятой Богородицы; Акафист
