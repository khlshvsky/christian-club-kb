## Богословие и его разделы
- Богословие {θεολογία} :: Слово о Боге: познание Бога и Его откровения, совершаемое верой в Церкви. По святым отцам, богослов — тот, кто чисто молится. => Догматическое богословие; Нравственное богословие; Боговедение
- Догматическое богословие :: Наука, излагающая догматы веры в систематическом порядке и по духу Православной Церкви (определение архиеп. Филарета Гумилевского). => Догмат; Богословие
- Нравственное богословие :: Раздел богословия о христианской жизни: о законе Божием, добродетелях, грехе и пути спасения. => Богословие; Заповедь
- Основное богословие :: Раздел, обосновывающий истинность христианского Откровения перед разумом; близок к апологетике. => Апологетика; Откровение Божественное
- Сравнительное богословие :: Изучение вероучения инославных исповеданий в сопоставлении с Православием. => Инославие
- Патрология :: Наука о жизни и творениях святых отцов и учителей Церкви. => Святые отцы; Учитель Церкви
- Литургика :: Наука о православном богослужении: его чинах, кругах и смысле. => Богослужение; Типикон
- Каноническое право :: Учение о священных правилах (канонах) Церкви и церковном устройстве. => Канон (правило); Книга правил
- Экзегетика :: Наука о толковании Священного Писания в согласии со святыми отцами. => Герменевтика; Толкование Писания
- Апофатическое богословие {ἀποφατική} :: Отрицательный путь богопознания: Бог выше всего, что можно о Нём сказать, поэтому о Нём говорят, отрицая всё тварное («Невидимый», «Непостижимый»). => Катафатическое богословие; Непостижимость Божия
- Катафатическое богословие {καταφατική} :: Положительный путь богопознания: Бога именуют по Его откровению и действиям в мире (Благой, Премудрый, Любовь). => Апофатическое богословие; Имена Божии

## Откровение и его источники
- Откровение Божественное :: То, что Бог Сам открыл людям, чтобы они правильно и спасительно веровали в Него и достойно чтили Его (Катихизис). [[Евр 1:1]] => Естественное откровение; Сверхъестественное откровение; Священное Предание; Священное Писание
- Естественное откровение :: Познание Бога через творение, совесть и разум, доступное всякому человеку. [[Рим 1:20]] => Откровение Божественное; Естественная теология
- Сверхъестественное откровение :: Непосредственное откровение Бога через пророков, апостолов и во всей полноте — через Сына Божия. [[Евр 1:1-2]] => Откровение Божественное; Боговоплощение
- Священное Предание {παράδοσις} :: Когда истинно верующие и чтущие Бога словом и примером передают друг другу и предки потомкам учение веры, закон Божий, Таинства и священные обряды (Катихизис). [[2 Фес 2:15]] => Священное Писание; Вселенские Соборы; Святые отцы
- Священное Писание :: Книги, написанные Духом Божиим через освящённых человеков — пророков и апостолов; называется Библией. [[2 Тим 3:16]] => Библия; Богодухновенность; Священное Предание
- Символ веры {σύμβολον} :: Краткое и точное изложение главных истин веры, составленное на I и II Вселенских Соборах; состоит из 12 членов. => Никео-Цареградский Символ веры; Догмат
- Догмат {δόγμα} :: Богооткровенная истина веры, определённая и утверждённая Церковью как непреложная и общеобязательная. => Символ веры; Вселенские Соборы; Богословское мнение
- Богословское мнение {θεολογούμενον} :: Частное суждение отца или учителя Церкви, не противоречащее догматам, но и не имеющее их общеобязательной силы. => Догмат; Согласие отцов
- Согласие отцов {consensus patrum} :: Единодушное учение святых отцов по вопросу веры — признак подлинного церковного Предания. => Святые отцы; Священное Предание
- Каноны Священного Писания :: Определённый Церковью состав богодухновенных книг. => Канонические книги; Неканонические книги
- Вероучение :: Совокупность догматов и истин веры, которые исповедует Церковь. => Догмат; Символ веры
- Вера {πίστις} :: Уверенность в невидимом как бы в видимом, в желаемом и ожидаемом как бы в настоящем. [[Евр 11:1]] => Надежда; Любовь; Оправдание
- Богопознание :: Познание Бога, начинающееся с откровения и веры и совершающееся очищением сердца и молитвой. [[Мф 5:8]] => Непостижимость Божия; Апофатическое богословие; Боговедение
- Боговедение :: Опытное знание Бога, даруемое чистым сердцем по мере жизни по заповедям; высшая ступень богопознания. [[Ин 17:3]] => Богопознание; Обожение
