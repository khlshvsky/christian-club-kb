## Закон и заповеди
- Естественный закон :: Закон, написанный в сердцах людей и свидетельствуемый совестью. [[Рим 2:14-15]] => Совесть
- Заповедь :: Повеление Божие, указывающее путь жизни и спасения. [[Мф 19:17]] => Десятословие; Заповеди блаженства
- Десятословие :: Десять заповедей, данных Богом через Моисея на Синае; две скрижали — о любви к Богу и к ближнему. [[Исх 20:1-17]] => Моисеев закон; Две заповеди любви
- Две заповеди любви :: Возлюби Господа Бога твоего… и ближнего твоего, как самого себя; на них утверждается весь закон. [[Мф 22:37-40]] => Любовь
- Заповеди блаженства :: Девять заповедей Нагорной проповеди о блаженстве. [[Мф 5:3-12]] => Нищета духовная; Кротость
- Нищета духовная :: Смиренное сознание своей духовной нищеты перед Богом — первая из заповедей блаженства. [[Мф 5:3]] => Смирение
- Плач :: Благословенная печаль о грехах — «блаженны плачущие». [[Мф 5:4]] => Покаяние (метанойя)
- Кротость :: Тихое расположение духа, не раздражающееся и не гневающееся. [[Мф 5:5]] => Гнев
- Миротворчество :: Стремление жить со всеми в мире и примирять враждующих. [[Мф 5:9]] => Заповеди блаженства
- Нагорная проповедь :: Учение Христа на горе о Царстве Небесном (Мф 5–7). => Заповеди блаженства

## Добродетели
- Добродетель :: Устойчивое расположение к добру, возращаемое благодатью и подвигом. [[2 Пет 1:5-7]] => Плоды Духа
- Богословские добродетели :: Вера, надежда и любовь. [[1 Кор 13:13]] => Вера; Надежда; Любовь
- Надежда :: Успокоение сердца в Боге с упованием, что Он печётся о нашем спасении и дарует обещанное блаженство (Катихизис). [[Евр 6:19]] => Вера; Отчаяние
- Любовь :: Высшая из добродетелей и союз совершенства: любовь к Богу и ближним. [[1 Кор 13:4-8]] => Две заповеди любви; Любовь Божия
- Смирение :: Сознание своей немощи и всецелое упование на Бога; основание всех добродетелей. [[Мф 11:29]] => Гордость; Нищета духовная
- Послушание :: Отсечение своей воли ради воли Божией и духовного руководителя. [[Флп 2:8]] => Монашество
- Целомудрие :: Цельность и чистота души и тела. => Блуд
- Нестяжание :: Свобода от пристрастия к имуществу. => Сребролюбие
- Воздержание :: Обуздание плоти и желаний. => Чревоугодие; Пост
- Терпение :: Мужественное перенесение скорбей с упованием на Бога. [[Лк 21:19]] => Долготерпение
- Милостыня :: Дело милосердия к нуждающимся, совершаемое тайно и с любовью. [[Мф 6:3-4]] => Дела милости телесные
- Дела милости телесные :: Алчущего напитать, жаждущего напоить, нагого одеть, посетить в темнице и больного, странника принять, умерших погребать (Катихизис). [[Мф 25:35-36]] => Дела милости духовные
- Дела милости духовные :: Обратить грешника, научить незнающего, подать добрый совет, молиться за ближнего, утешить печального, не воздавать злом, прощать обиды (Катихизис). => Дела милости телесные
- Страх Божий :: Благоговение перед Богом и опасение оскорбить Его. => Дух страха Божия
- Благочестие :: Жизнь, во всём посвящённая Богу. [[1 Тим 4:8]] => Дух благочестия

## Молитва
- Молитва :: Возношение ума и сердца к Богу (Катихизис); бывает хвалебная, благодарственная и просительная. [[1 Фес 5:17]] => Молитва Господня; Умная молитва
- Умная молитва :: Молитва умом в сердце, особенно Иисусова. => Иисусова молитва; Исихазм
- Молитвенное правило :: Ежедневные утренние и вечерние молитвы. => Молитва
- Земной поклон :: Поклон до земли — знак покаяния и благоговения. => Молитва
