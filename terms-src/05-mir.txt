## Творение мира
- Творение из ничего {ex nihilo} :: Бог сотворил мир не из какого-либо вещества, а из ничего, единым Своим словом и свободной волей. [[Евр 11:3]] => Шестоднев; Свобода Божия
- Шестоднев :: Повествование книги Бытия о творении мира в шесть дней; толковали его свт. Василий Великий и другие отцы. [[Быт 1:1]] => Творение из ничего; Пятикнижие
- Мир видимый и невидимый :: Бог — Творец «всем видимым же и невидимым»: вещественного мира и мира духовного (ангелов). => Ангелы; Никео-Цареградский Символ веры
- Цель творения :: Бог сотворил мир не по нужде, но по благости, чтобы и другие творения прославляли Его и были причастниками Его блаженства. => Благость Божия; Обожение
- Совершенство мира :: Всё сотворённое Богом «добро зело»; зло вошло в мир не от Бога, а через падение свободных тварей. [[Быт 1:31]] => Зло; Грехопадение
! Пантеизм :: Учение, отождествляющее Бога с миром; противоречит различию Творца и твари. => Творение из ничего
! Дуализм :: Учение о двух равных началах — добром и злом; отвергнуто Церковью (манихейство). => Манихейство; Зло

## Промысл Божий
- Промысл Божий :: Непрестанная всемогущая сила, премудрость и благость Божия, которой Бог сохраняет бытие и силы тварей, направляет их к благим целям, а злу пресекает или исправляет его к добру (Катихизис). [[Мф 10:29-30]] => Сохранение мира; Управление миром; Содействие
- Сохранение мира :: Действие Промысла, которым Бог поддерживает бытие и силы тварей. [[Евр 1:3]] => Промысл Божий
- Содействие :: Действие Промысла, которым Бог помогает тварям в их добрых делах, не стесняя свободы. [[Флп 2:13]] => Синергия
- Управление миром :: Действие Промысла, которым Бог направляет всё к благой цели. => Промысл Божий
- Попущение :: Бог допускает зло, не желая его, ради свободы тварей и обращая его к добру. => Промысл Божий; Зло
- Чудо :: Действие Божие, превышающее естественные силы и законы природы, для подтверждения истины и спасения людей. [[Ин 2:11]] => Знамение
- Знамение :: Чудесный знак, указывающий на присутствие и волю Божию. => Чудо
- Зло :: Не существо, а отпадение свободной воли от Бога и добра; Бог не творец зла. => Грех; Попущение; Теодицея

## Ангелы
- Ангелы {ἄγγελοι} :: Бестелесные духи, одарённые умом, волей и могуществом, сотворённые Богом прежде видимого мира; имя означает «вестники». [[Евр 1:14]] => Небесная иерархия; Ангел-хранитель
- Небесная иерархия :: Девять чинов ангельских в трёх иерархиях, по учению, изложенному в творениях св. Дионисия Ареопагита. => Серафимы; Херувимы; Архангелы
- Серафимы :: «Пламенеющие» — высший ангельский чин, ближайший к Богу, воспевающий Трисвятое. [[Ис 6:2-3]] => Небесная иерархия; Трисвятое
- Херувимы :: Ангельский чин высшей иерархии, «многоочитые», исполненные ведения. [[Быт 3:24]] => Небесная иерархия; Херувимская песнь
- Престолы :: Ангельский чин первой иерархии, на котором Бог как бы почивает. [[Кол 1:16]] => Небесная иерархия
- Господства :: Чин второй иерархии; по Ареопагиту, управляет низшими чинами. [[Кол 1:16]] => Небесная иерархия
- Силы :: Чин второй иерархии; через них совершаются чудеса. [[Еф 1:21]] => Небесная иерархия
- Власти :: Чин второй иерархии, укрощающий силу диавола. [[Кол 1:16]] => Небесная иерархия
- Начала :: Чин третьей иерархии, управляющий царствами и народами. [[Еф 3:10]] => Небесная иерархия
- Архангелы :: «Начальники ангелов», благовестники великого и преславного (Михаил, Гавриил, Рафаил и др.). [[1 Фес 4:16]] => Михаил архангел; Гавриил архангел
- Михаил архангел :: «Кто как Бог» — архистратиг небесных сил, победивший диавола. [[Откр 12:7]] => Архангелы
- Гавриил архангел :: «Крепость Божия» — благовестник Боговоплощения, возвестивший Деве Марии. [[Лк 1:26]] => Благовещение
- Ангел-хранитель :: Ангел, даруемый каждому христианину от Крещения для охранения на пути спасения. [[Мф 18:10]] => Ангелы
- Падение ангелов :: Часть ангелов во главе с денницей возгордилась и отпала от Бога, став злыми духами. [[Иуд 1:6]] => Диавол; Бесы; Гордость
- Диавол {διάβολος} :: «Клеветник» — падший ангел, противник Бога и человека, искуситель прародителей. [[Ин 8:44]] => Сатана; Денница; Падение ангелов
- Сатана :: «Противник» — имя главы падших духов. [[Мф 4:10]] => Диавол
- Денница (Люцифер) :: Образное имя первого из ангелов до его падения. [[Ис 14:12]] => Диавол; Гордость
- Бесы :: Злые духи, падшие ангелы, искушающие людей ко греху. [[Еф 6:12]] => Диавол; Искушение; Невидимая брань
