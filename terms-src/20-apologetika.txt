## Основные понятия
- Апологетика {ἀπολογία} :: Защита и обоснование христианской веры перед разумом; «будьте всегда готовы дать ответ». [[1 Пет 3:15]] => Основное богословие; Апологеты
- Естественная теология :: Познание о Боге, доступное разуму из рассмотрения мира и человека. => Естественное откровение; Доказательства бытия Божия
- Вера и разум :: Разум не противоречит вере, но не может постичь тайн Откровения своими силами; вера просвещает разум. => Вера
- Теодицея :: «Оправдание Бога» — ответ на вопрос о зле в мире, сотворённом благим Богом. => Зло; Свобода воли
- Личностное объяснение :: Объяснение события через деятеля — его намерение, знание и способности, — а не через начальные условия и законы природы; теизм объясняет бытие и порядок мира именно так. => Индуктивный аргумент

## Доказательства бытия Божия
- Доказательства бытия Божия :: Рассуждения разума, показывающие разумность веры в Бога; по архиеп. Филарету, это «показания», а не строгие доказательства. => Бытие Божие
- Космологический аргумент :: От существования мира к его первопричине. => Доказательства бытия Божия
- Телеологический аргумент :: От порядка и целесообразности мира к Премудрому Устроителю. [[Пс 103:24]] => Доказательства бытия Божия
- Онтологический аргумент :: От понятия о совершеннейшем Существе к Его бытию. => Доказательства бытия Божия
- Нравственный аргумент :: От нравственного закона и совести к Законодателю. => Совесть
- Исторический аргумент :: От всеобщности религиозной веры у народов. => Доказательства бытия Божия
- Аргумент от религиозного опыта :: От свидетельства тех, кто опытно познал Бога. => Боговедение
- Индуктивный аргумент :: Довод, при котором посылки не влекут вывод с необходимостью, а делают его вероятнее: C-индуктивный (от англ. confirm) повышает вероятность вывода, P-индуктивный (от англ. probable) делает её выше половины. => Личностное объяснение; Доказательства бытия Божия

## Мировоззрения
! Атеизм :: Отрицание бытия Божия; по Писанию — «безумие» сердца. [[Пс 13:1]] => Бытие Божие
! Агностицизм :: Учение о невозможности познать, есть ли Бог. => Богопознание
! Деизм :: Признание Бога Творцом при отрицании Промысла и Откровения. => Промысл Божий
! Материализм :: Учение, признающее существующим только вещество. => Духовность Божия; Душа
- Теизм :: Вера в личного Бога — Творца и Промыслителя мира. => Монотеизм
