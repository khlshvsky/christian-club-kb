## Познание Бога
- Бытие Божие :: Истина, что Бог есть; открывается в Откровении и подтверждается свидетельствами разума и совести. [[Евр 11:6]] => Доказательства бытия Божия; Откровение Божественное
- Непостижимость Божия :: Сущность Божия непостижима для твари: Бога знаем по Его откровению и действиям, но не по существу. [[1 Тим 6:16]] => Апофатическое богословие; Сущность Божия
- Сущность Божия {οὐσία} :: То, что Бог есть Сам в Себе; непостижима и неприобщаема для творений. => Энергии Божественные; Непостижимость Божия
- Энергии Божественные {ἐνέργειαι} :: Нетварные действия Божии, в которых Бог действительно открывается и сообщается творению, оставаясь непостижимым по сущности (учение свт. Григория Паламы, утверждённое Соборами 1341–1351 гг.). [[2 Пет 1:4]] => Сущность Божия; Фаворский свет; Обожение; Паламизм
- Фаворский свет :: Нетварный свет Божества, явленный при Преображении Господнем и созерцаемый святыми. [[Мф 17:2]] => Энергии Божественные; Преображение Господне; Исихазм
- Богоявление (теофания) :: Явление Бога человеку в видимых образах — в купине, в облаке, при Крещении Господнем. => Крещение Господне; Ветхий Завет
- Антропоморфизмы Писания :: Выражения Писания, приписывающие Богу человеческие члены и чувства; понимаются духовно, применительно к нашему разумению (Катихизис). => Духовность Божия

## Свойства Божии
- Свойства Божии :: Совершенства Божии, открытые нам; одни отличают Бога от тварей (отрицательные), другие выражают сходство с духовными свойствами человека (положительные). => Апофатическое богословие; Катафатическое богословие
- Самобытность :: Бог имеет бытие от Себя Самого и ни от чего не зависит. [[Исх 3:14]] => Сущий; Свойства Божии
- Вечность Божия :: Бог безначален и бесконечен, выше времени. [[Пс 89:3]] => Неизменяемость
- Неизменяемость :: Бог всегда один и тот же, у Него нет изменения и тени перемены. [[Иак 1:17]] => Вечность Божия
- Вездеприсутствие :: Бог присутствует везде, всё наполняет Собой, не будучи ограничен пространством. [[Пс 138:7]] => Свойства Божии
- Духовность Божия :: Бог есть Дух бестелесный и невидимый. [[Ин 4:24]] => Антропоморфизмы Писания
- Всеведение :: Бог знает всё — прошедшее, настоящее, будущее и самые помышления. [[Евр 4:13]] => Предведение; Премудрость Божия
- Премудрость Божия :: Совершенное знание и благое избрание целей и средств; также имя Сына Божия. [[1 Кор 1:24]] => Всеведение; Логос
- Всемогущество :: Бог может всё, что хочет, и то, что не противно Его совершенствам. [[Лк 1:37]] => Вседержитель
- Святость Божия :: Совершенная чистота от греха и любовь к добру; Бог — источник всякой святости. [[1 Пет 1:16]] => Святость
- Благость Божия :: Бог любит Своё творение и изливает на него блага; Бог есть любовь. [[1 Ин 4:8]] => Любовь Божия
- Любовь Божия :: Высшее откровение Бога: Он так возлюбил мир, что отдал Сына Своего Единородного. [[Ин 3:16]] => Благость Божия; Искупление
- Правосудие Божие :: Бог воздаёт каждому по делам его, награждая добро и наказывая зло. [[Рим 2:6]] => Страшный суд
- Блаженство Божие :: Бог всеблажен и не нуждается ни в чём. [[1 Тим 6:15]] => Свойства Божии
- Свобода Божия :: Бог творит и действует не по необходимости, но по Своей свободной благой воле. [[Еф 1:11]] => Творение из ничего
- Единство Божие :: Бог един по существу; нет иного Бога. [[Втор 6:4]] => Святая Троица; Монотеизм

## Имена Божии
- Имена Божии :: Наименования, которыми Бог открыл Себя в Писании и в Своих действиях. => Катафатическое богословие
- Сущий {ὁ ὤν} :: Имя, открытое Моисею у купины: «Я есмь Сущий»; означает самобытность. На иконах Спасителя пишется ὁ ὤν. [[Исх 3:14]] => Яхве; Самобытность
- Яхве (Иегова) :: Священное ветхозаветное имя Бога («Сущий»), которое иудеи не произносили, заменяя словом «Адонаи». => Сущий; Адонаи
- Элохим :: Еврейское имя «Бог» во множественном числе; отцы видели в нём указание на тайну Троицы. [[Быт 1:1]] => Святая Троица
- Адонаи :: «Господь», в Септуагинте — Κύριος. => Яхве; Господь
- Господь {Κύριος} :: Имя Бога как Владыки всего; апостолы прилагают его ко Христу, исповедуя Его Богом. [[Флп 2:11]] => Адонаи
- Саваоф :: «Господь сил (воинств)» — Владыка небесных воинств. [[Ис 6:3]] => Ангелы
- Вседержитель {Παντοκράτωρ} :: Бог, всё держащий в Своей власти; иконописный образ Христа Пантократора. => Всемогущество
- Отец :: Имя первого Лица Святой Троицы; также указание на отношение Бога к людям по благодати усыновления. [[Мф 6:9]] => Бог Отец; Молитва Господня
- Монотеизм :: Вера в Единого Бога; в христианстве раскрыта как вера в Единого Бога в Троице. => Единство Божие; Святая Троица
