## Круги богослужения
- Богослужение :: Общественное служение Богу молитвой, песнопениями и священнодействиями по уставу Церкви. => Суточный круг; Седмичный круг; Годовой круг
- Суточный круг :: Службы суток: вечерня, повечерие, полунощница, утреня, часы (1, 3, 6, 9) и Литургия; церковные сутки начинаются вечером. => Вечерня; Утреня; Часы
- Седмичный круг :: Посвящение дней седмицы: воскресенье — Воскресению, понедельник — бесплотным силам, среда и пятница — Кресту и страданиям Господа и т. д. => Октоих
- Годовой круг :: Праздники и памяти святых в течение года — неподвижные (Минея) и подвижные, зависящие от Пасхи (Триодь). => Двунадесятые праздники; Минея; Триодь
- Пасхалия :: Правила вычисления дня Пасхи, от которого зависят подвижные праздники. => Пасха
- Юлианский календарь :: Старый стиль, которым пользуется в богослужении Русская Церковь. => Пасхалия
- Типикон (Устав) :: Книга, определяющая порядок совершения всех богослужений. => Богослужебные книги

## Службы
- Божественная литургия :: Главное богослужение, на котором совершается Таинство Евхаристии. => Проскомидия; Литургия оглашенных; Литургия верных
- Литургия свт. Иоанна Златоуста :: Чин Литургии, совершаемый в большинство дней года. => Божественная литургия; Иоанн Златоуст
- Литургия свт. Василия Великого :: Чин Литургии, совершаемый 10 раз в году: по воскресеньям Великого поста, в Великие четверг и субботу и др. => Божественная литургия; Василий Великий
- Литургия Преждеосвященных Даров :: Вечерня с причащением Дарами, освящёнными на прежней Литургии; совершается в будни Великого поста. => Великий пост
- Литургия ап. Иакова :: Древнейший чин Литургии, совершаемый в день памяти апостола Иакова, брата Господня. => Божественная литургия
- Проскомидия {προσκομιδή} :: «Приношение» — первая часть Литургии: приготовление Даров на жертвеннике и поминовение живых и усопших. => Просфора; Агнец (литургический); Жертвенник
- Литургия оглашенных :: Вторая часть Литургии с чтением Апостола и Евангелия; на ней могли присутствовать оглашенные. => Оглашенные
- Литургия верных :: Третья часть Литургии, на которой совершается Таинство Евхаристии. => Анафора
- Всенощное бдение :: Служба накануне воскресных и праздничных дней, соединяющая вечерню, утреню и первый час. => Вечерня; Утреня
- Вечерня :: Служба вечерних часов, начало церковных суток. => Суточный круг
- Утреня :: Служба утренних часов с чтением канона, а в праздники — Евангелия. => Канон (песнопение); Полиелей
- Повечерие :: Служба на сон грядущим; в Великий пост читается Великое повечерие. => Суточный круг
- Полунощница :: Служба полуночная — в память о молитве Спасителя в Гефсимании. => Суточный круг
- Часы :: Краткие службы первого, третьего, шестого и девятого часа. => Суточный круг
- Полиелей :: «Многомилостивие» — торжественная часть утрени праздничных дней с пением псалмов 134–135. => Утреня
- Молебен :: Краткое благодарственное или просительное богослужение. => Треба
- Панихида :: Заупокойная служба о упокоении усопших. => Поминовение усопших
- Литургический пост :: Воздержание от пищи с полуночи перед Причащением. => Приготовление к Причастию

## Песнопения и молитвы
- Ектения {ἐκτένεια} :: «Протяжное» моление — ряд прошений, произносимых диаконом или священником, с ответом хора «Господи, помилуй». => Богослужение
- Тропарь :: Краткое песнопение, выражающее суть праздника или подвиг святого. => Кондак
- Кондак :: Краткое песнопение праздника; изначально — пространная поэма (прп. Роман Сладкопевец). => Тропарь; Акафист
- Канон (песнопение) :: Сложное песнопение из девяти (обычно восьми) песней, построенных на библейских песнях. => Ирмос; Утреня
- Ирмос :: Первая строфа песни канона, образец для последующих тропарей. => Канон (песнопение)
- Стихира :: Песнопение, исполняемое со стихами псалмов на вечерне и утрене. => Вечерня
- Акафист {ἀκάθιστος} :: «Неседальное» песнопение — хвалебное, поётся стоя; первообраз — Акафист Пресвятой Богородице. => Кондак; Ходатайство Богородицы
- Прокимен :: Стих псалма, предваряющий чтение Писания. => Апостол (книга)
- Антифон :: Песнопение, исполняемое попеременно двумя хорами. => Литургия оглашенных
- Херувимская песнь :: Песнопение Литургии верных перед Великим входом: «Иже херувимы тайно образующе…». => Херувимы; Великий вход
- Трисвятое :: «Святый Боже, Святый Крепкий, Святый Безсмертный, помилуй нас». => Серафимы
- Великий вход :: Перенесение Даров с жертвенника на престол на Литургии верных. => Херувимская песнь
- Малый вход :: Вход с Евангелием на Литургии оглашенных. => Литургия оглашенных
- Кафизма :: Один из 20 разделов Псалтири для богослужебного чтения. => Псалтирь
- Молитва Господня :: «Отче наш» — молитва, которой Господь научил апостолов; содержит призывание, семь прошений и славословие. [[Мф 6:9-13]] => Молитва
- Иисусова молитва :: «Господи Иисусе Христе, Сыне Божий, помилуй мя, грешнаго» — краткая непрестанная молитва. => Умная молитва; Исихазм
- Аминь :: «Истинно, да будет так» — утверждение молитвы. => Молитва

## Богослужебные книги
- Богослужебные книги :: Книги, содержащие тексты и порядок служб. => Типикон (Устав); Служебник
- Служебник :: Книга для священника и диакона с чинами Литургии, вечерни и утрени. => Божественная литургия
- Требник :: Книга чинопоследований Таинств и треб. => Треба
- Часослов :: Книга неизменяемых частей суточного круга. => Суточный круг
- Октоих :: «Осмогласник» — песнопения седмичного круга на восемь гласов. => Глас; Седмичный круг
- Минея :: Книга служб святым и неподвижным праздникам по месяцам года. => Годовой круг
- Триодь :: Постная (от Недели о мытаре и фарисее до Пасхи) и Цветная (от Пасхи до Недели всех святых). => Годовой круг; Великий пост
- Глас :: Один из восьми напевов (осмогласие) церковного пения. => Октоих
